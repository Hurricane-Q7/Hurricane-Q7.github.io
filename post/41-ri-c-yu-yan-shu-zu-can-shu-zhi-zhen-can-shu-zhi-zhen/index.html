4.1日-C语言-数组参数、指针参数（指针）

2026-04-01 3 min read # C语言学习笔记

实参与形参类型应该保持一致!
形参那里如何设计，取决于你函数调用语句里传的参数类型！！！

数组参数

数组传参可以通过数组和指针的两种方式来接收！

一维数组传参

#include <stdio.h>
void test(int arr[])//ok? 可以，通过数组的方式来接收地址
{}
void test(int arr[10])//ok?可以，同上
{}
void test(int *arr)//ok? 可以，创建一个int* 型指针变量arr，来接收参数
{}
void test2(int* arr[20])//ok? 可以，20可以省略
{}
void test2(int* *arr)//ok? 可以，创建一个二级指
{}
int main()
{
    int arr[10]={0};//普通int数组，数组名代表首元素地址，是int*
    int* arr2[20] = {0};//指针数组，存放int* 型指针

    test(arr);
    test2(arr2);//arr2是首元素地址（arr2[0]）,首元素是int* 型的数据类型，可以通过二级指针变量（int* * 变量名）来接收
}

二维数组传参

void test(int arr[3][5])//ok？可以
{}
void test(int arr[][])//ok？不可以
{}
void test(int arr[][5])//ok？可以
{}
//总结：二维数组传参，函数形参的设计只能省略第一个[]的数字。
//因为对一个二维数组，可以不知道有多少行，但是必须知道一行多少元素。
//这样才方便运算。
void test(int *arr)//ok？不可以，类型不匹配
{}
void test(int* arr[5])//ok？不可以，类型不匹配
{}
void test(int (*arr)[5])//ok？可以
{}
void test(int **arr)//ok？不可以，类型不匹配
{}
int main()
{
 int arr[3][5] = {0};
 test(arr);//所以这里的arr类型是int (*) [5]，5代表一行有5个元素
 //对于二维数组来说，二维数组把每一行的元素整体化一个一维数组，可以理解为一个二维数组由多个一维数组组成，那么二维数组的首地址就是第一行的地址，也即是一维数组的地址，类型是数组指针类型的，eg:
 //int (*) [5]这样的
}
