学习计算机遇到的陌生单词

2026-02-24 2 min read

words

  1. initialize v. 初始化（计）.
    编程里的核心定义
    给变量 / 数组 / 对象 分配内存并赋予一个确定的、可用的值（而非内存里的随机 “垃圾值”），就叫 “初始化”；guess_is_initialized 这个变量名直译就是 “guess 是否已初始化”。
  2. implement核心意思是 “实现”，特指把设计、思路、需求、算法等抽象的东西，用代码写出来、落地成可运行的功能。implement 侧重 “把想法变成可运行的代码”，更强调 “落地、完成”。
  3. reserve v. 保留[储备] ；
  4. the terminating null character 指的是'\0'（C语言中字符串的结束标志）
  5. browser n.浏览者
  6. redirect v.重定向（计）eg:You were redirected to another page.
  7. Configuration n. 配置
system configuration（系统配置）
hardware configuration（硬件配置）
  1. argument n.参数 eg :Each of these functions returns its argument if successful.
  2. Patameter n.参数
  3. overwrite 覆盖、重写
  4. configure v. 按特定方式）安置；（尤指对计算机设备进行）配置；对（设备或软件进行）设定
  5. protocol n.（数据传输）协议！
  6. allocate v. 分配...给，拨...（给）
