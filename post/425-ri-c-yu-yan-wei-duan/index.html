2026-04-25 7 min read # C语言学习笔记

C语言的标识符只能由数字、字母、下划线组成，且第一个字符必须是字母或下划线。

位段

C语言的标识符只能由数字、字母、下划线组成，且第一个字母必须是字母或下划线。
位段（Bit-fields）不是一种独立的数据类型，它是结构体（struct）的一种特殊用法。

member

1.位段的成员必须是 int、unsigned int 或signed int 。
2.位段的成员名后边有一个冒号和一个数字。

struct A
{ 
    int _a:2;//_a这个变量只被分配2个bit位
    int _b:5;//同理
    int _c:10;
    int _d:30;
};
//位段是可以节省内存空间的
sizeof(struct A);//?
//看上面4个变量，一共需要47个bit位，一个一个来看，_a用两个就可以了，_b用5个，_c用10个，_c用30个，由于数据的类型还是int，这里还是先分配一个int大小的内存空间（32bits），这一个内存空间
//一口气可以放下_a,b,c这三个变量，但是缺放不下_d，所以要再开辟一个内存空间来存放_d的30个bit位，所以strut的类型是8byte，但是这30个bit位的存放情况是不清楚的，是一口气存放在第二个空间呢，还是再第一个空间存一部分第二个再一部分呢？不确定

内存分配

  1. 位段的成员可以是 int unsigned int signed int 或者是 char （属于整形家族）类型
  2. 位段的空间上是按照需要以4个字节（ int ）或者1个字节（ char ）的方式来开辟的。
  3. 位段涉及很多不确定因素，位段是不跨平台的，注重可移植的程序应该避免使用位段。

位段的跨平台问题

  1. int 位段被当成有符号数还是无符号数是不确定的。
  2. 位段中最大位的数目不能确定。（16位机器最大16，32位机器最大32，写成27，在16位机
    器会出问题。
  3. 位段中的成员在内存中从左向右分配，还是从右向左分配标准尚未定义。
  4. 当一个结构包含两个位段，第二个位段成员比较大，无法容纳于第一个位段剩余的位时，是
    舍弃剩余的位还是利用，这是不确定的。
    总结：
    跟结构相比，位段可以达到同样的效果，但是可以很好的节省空间，但是有跨平台的问题存在。

枚举（Enumeration）

在C语言中，枚举（Enumeration，简称 enum） 是一种由用户定义的整型常量(也称为枚举常量)集合。简单来说，它就是给一串整数起了一堆“好记的名字”，让代码的可读性瞬间提升

enum Day
//enum是枚举类型的关键字，Day是自定义标签
{
    Mon,
    Tues,
    Wed,
    Thur,//每个枚举常量之间要用逗号隔开
    Fri,
    Sat,
    Sun
};//和结构体一样，结尾带上分号
enum Sex
{
    Male;
    Female;
    Secret;
};
enum Color
{
    RED,
    GREEN,
    BLUE
};

花括号里面的东西称为枚举常量，也有可能的取值，默认从0开始，一次递增1，也可以在定义的时候赋予初值。

enum Day
{
	Mon=1,
	Tues,//2
	Wen,//3
	Tur,//4
	Fri,//5
	Sat,//6
	Sun//7
};
int main()
{
    enum Day d = Mon;//用枚举常量来给枚举变量赋值，这样更加严谨
	printf("%d\n", Mon);//1
	printf("%d\n", Tues);
	printf("%d\n", Wen);
	printf("%d\n", Tur);
	printf("%d\n", Fri);
	printf("%d\n", Sat);
	printf("%d\n", Sun);//7
	return 0;
}

枚举的Advantages

我们可以使用 #define 定义常量，为什么非要使用枚举？
枚举的优点：

  1. 增加代码的可读性和可维护性
  2. 和#define定义的标识符比较枚举有类型检查，更加严谨。(C++里面的)
  3. 防止了命名污染（封装）
  4. 便于调试 （define替换的话会替换，而枚举不替换）
  5. 使用方便，一次可以定义多个常量
    这些东西要多写代码才会理解的更加深刻，写的代码多了才会更加认同枚举是很方便的！

联合体（共用体）

联合体是C语言中一种自定义数据类型，也被叫作为共用体，最大的特点就是联合体内部的成员会公用一块内存空间。

union 联合体名 {
    类型1 成员1;
    类型2 成员2;
    ...
};
union un
{
	int a;
	char c;
};

union的核心特点

核心特点（最重要）

  • 所有成员共用同一块内存空间
  • 同一时间只能存放一个成员的值
  • 联合体大小 = 最大成员的大小
int main()
{
	union un
	{
		int a;//4个字节
		char c;
	};
	union un u;
	printf("%d\n", sizeof(union un));
	printf("%p\n", &u);
	printf("%p\n", &u.a);
	printf("%p\n", &u.c);//打印发现，内部成员的起始地址都是一样的，说明它们会共同使用一块内存空间
	return 0;
}

用联合体来判断大小端存储

int check_sys()
{
	//内存地址：低------>高
	//1的十六进制
	//0x00 00 00 01
	//小端存放
	//0x01 00 00 00
	union un
	{
		int a;
		char c;
	}u;
	u.a = 1;
	//return *(char*)&u;//可以这样写
	return u.c;
}
int main()
{
	int ret = check_sys();
	if (ret == 1)
	{
		printf("小端存放!");
	}
	else {
		printf("大端存放!");
	}
	return 0;
}

联合体 = 共享内存的多类型变量，同一时间只用一个，省空间。

union大小的计算

  • 联合的大小至少是最大成员的大小。
  • 当最大成员大小不是最大对齐数的整数倍的时候，就要对齐到最大对齐数的整数倍。
union Un1
{
	char c[5];//对齐数：1
	int i;//对齐数：4
};

union Un2
{
	short arr[7];//对齐数：2，short类型两个字节
	int i;
    //arr[7]一共占14个字节，Int i 和该数组起始地址是一样的，但是对齐数不一样，这里选择最大对齐数是4，14个字节不是4的倍数，所以要对齐到16个字节
};

int main()
{
	printf("%d\n", sizeof(union Un1));//8 Byte
	printf("%d\n", sizeof(union Un2));//16 Byte
	return 0;
}

相关的练习题

union Test {
    int a;
    char b[4];
};

int main() {
    union Test t;
    t.a = 0x12345678;
    //小端存储：78 56 34 12
    //由于联合体成员共用一块内存空间，共同使用4个字节的大小，而且起始地址是一样的，u.a里面的数据分为4个字节，依次为78 56 34 12 这4个部分，数组b有4个元素刚好放得下这4个字节得内容。
    printf("%x\n", t.b[0]);
    printf("%x\n", t.b[1]);
    printf("%x\n", t.b[2]);
    printf("%x\n", t.b[3]);

    return 0;
}
