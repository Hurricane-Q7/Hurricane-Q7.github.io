C语言-常见动态内存错误与常见笔试题

2026-05-23 2 min read # C语言学习笔记

核心三步骤：
malloc 申请 →\rightarrow→ 判 NULL 使用 →\rightarrow→ free 释放

常见错误

  1. 对NULL指针的解引用操作
  2. 对动态开辟空间的越界访问
  3. 对非动态开辟内存使用free释放
  4. 使用free释放一块动态开辟内存的一部分
  5. 对同一块动态内存多次释放
  6. 动态开辟内存忘记释放（内存泄漏）

错误情况代码

错误情况一：

动态内存有风险，用前必判 NULL。
 void test()
 {
     int *p = (int*)malloc(INT_MAX/4);
     *p = 20;//如果P的值是NULL，就有问题。
     free(p);
 }

错误情况二：

void test()
{
    int i = 0;
    int*p = (int *)malloc(10*sizeof(int));
    if(NULL == p)
    {
        ;
    }
    for(i=0;i<=10;i++)
    {
        *(p+i ) = i ;
        free(p);
    }
}

错误情况三：

void test()
{
    int a = 10;
    int *p = &a;
    free(p);
}

这段代码犯了一个 C 语言内存管理中非常严重的错误：试图去释放（free）一块局部的、位于栈区（Stack）的内存。

错误情况四：

void test()
{
    int *p = (int*)malloc(100);
    p++;
    free(p);
}

错误情况五：

void test()
{
    int *p = (int *)malloc(100);
    free(p);
    free(p);
}

错误情况六：动态开辟内存忘记释放（内存泄漏）

void Test(void)
{
 char *str = (char *) malloc(100);
 strcpy(str, "hello");
 free(str);
 if(str != NULL)
 {
 strcpy(str, "world");
 printf(str);
 }
}

char* GetMemory()
{
	char p[] = "hello world";
    //栈区上的一个局部变量，栈区上的内存由操作系统自动管理，是临时的
    //所以，当函数调用完之后，p就成了一个野指针！！！
	return p;
}
void Test()
{
	char* str = NULL;
	str = GetMemory();
	printf(str);
}
int main()
{
	Test();
	return 0;
}

void Test(void)
{
	char* str = (char*)malloc(100);
	strcpy(str, "hello");
	free(str);
    //free函数只是释放内存空间，不会修改指针变量的值
	if (str != NULL)
	{
		strcpy(str, "world");
		printf(str);
	}
}
int main()
{
	Test();
	return 0;
