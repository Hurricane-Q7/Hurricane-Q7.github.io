C++-类和对象-继承

2026-09-20 6 min read

继承（inheritance）

继承：
继承是类与类之间的一种关系。继承关系中，继承者称为子类（派生类），被继承的类称为父类（基类）。
子类继承父类后，子类对象中会包含一个父类的基类部分，因此子类可以复用父类的成员和功能，从而减少重复代码。

关于继承的注意事项

  • 子类对象中的父类成员，属于这个子类对象自己的一份数据。
  • 不同对象之间不共享成员变量。
  • Base b1 和 Son s1 是两个不同的对象，因此 s1.m_a 和 b1.m_a 是两份独立的数据。
  • 成员函数并不是简单地“复制一份到每个对象中”，而是子类可以通过继承关系使用父类的成员函数。
    关键：继承不是让父类对象和子类对象共享同一份内存，而是建立一种类之间的复用关系。

继承相关的英文单词

inheritance 继承
inherit 继承（verb）
base class ——基类、父类
derived class ——派生类、子类
parent class ——父类
child class ——子类

继承的好处：减少重复代码的书写
子类对象 = 父类子对象 + 子类自己的成员
派生类中的成员，包含两大部分：
一类是从基类继承过来的，一类是自己增加的成员。
从基类继承过过来的表现其共性，而新增的成员体现了其个性。

继承的基本方式

  • 公共继承
  • 保护继承
  • 私有继承

    无论采用何种继承方式，父类的 private 成员对子类都是不可直接访问的。它仍属于父类子对象的一部分，但子类只能通过父类提供的 public/protected 成员函数间接操作。
继承模型图：
Son对象
┌─────────────────┐
│ Father子对象     │
│ ├─ private a    │ ← 存在，但Son不能直接访问
│ └─ protected b  │ ← 孙Son可以直接访问
│ └─ public c     │ ← Son可以直接访问
├─────────────────┤
│ Son自己的成员    │
│ └─ d            │
└─────────────────┘
继承不是父类和子类“共享同一个成员”，而是子类对象中包含了一份父类子对象，

继承中的对象模型

结论：父类中私有成员也是被子类继承下去了，只是由编译器给隐藏后访问不到了。

继承中构造和析构顺序

结论：

  1. 即使没有创建父类对象，子类在继承父类时，也会创建一个父类对象（先有父亲，再有儿子）
  2. 继承中，先调用父类构造函数，在调用子类构造函数，析构顺序与构造相反
class Father
{
public:
	Father()
	{
		cout << "Father默认构造函数调用。" << endl;
	}
	~Father()
	{
		cout << "Father析构函数调用。" << endl;
	}
};
class Son : public Father
{
public:
	Son()
	{
		cout << "Son默认构造函数调用。" << endl;
	}
	~Son()
	{
		cout << "Son析构函数调用。" << endl;
	}
};
void test01()
{
	Son s1;
}
int main()
{
	test01();
	system("pause");
	return 0;
}

继承同名成员处理方式

问题：当子类与父类出现同名的成员，如何通过子类对象，访问到子类活父类中同名的数据呢？

  • 访问子类同名成员，直接访问即可
  • 访问父类同名成员，需要加作用域
class Base
{
public:
	Base()
	{
		this->m_a = 100;
	}
	void func()
	{
		cout << "Base 类 中func函数调用。" << endl;
	}
	int m_a;
};
class Son:public Base
{
public:
	Son()
	{
		this->m_a = 200;
	}
	void func()
	{
		cout << "Son 类中func函数调用。" << endl;
	}
	int m_a;
};
void test01()
{
	//同名成员变量情况处理
	Son s1;
	cout << "Son  中的m_a = " << s1.m_a << endl;
	cout << "Base 中的m_a = " << s1.Base::m_a << endl;//子类对象访问父类同名成员需要添加作用域
}
void test02()
{
	//同名成员函数情况处理
	Son s2; 
	s2.func();
	s2.Base::func();//子类对象调用父类的成员函数要加作用域，因为子类会隐藏父类中同名成员函数

}
int main()
{
	test02();
	system("pause");
	return 0;
}

总结：

  1. 子类对象可以直接访问到子类中同名成员
  2. 子类对象加作用域（父类的）可以访问到父类同名成员。
  3. 当子类与父类拥有同名的成员函数，子类会隐藏父类中同名成员函数，加作用域可以访问到父类中同名函数。

同名静态成员处理

`总结:同名静态成员处理方式和非静态处理方式一样，只不过有两种访问方式（通过对象 和 通过类名·）

class Base
{
public:
	static int m_a;
};
int Base::m_a = 100;

class Son : public Base
{
public:
	static int m_a;
};
int Son::m_a = 200;
void test01()
{
	Son s1;
	cout << "### 通过对象访问静态成员变量：###" << endl;
	cout << "Son s1.m_a = " << s1.m_a << endl;//200,子类对象直接访问子类静态成员变量
	cout << "Base s1.m_a = " << s1.Base::m_a << endl;//100
	cout << "### 通过类名来访问静态成员变量：###" << endl;
	cout << "Son m_a = " << Son::m_a << endl;
	cout << "Base m_a = " << Son::Base::m_a << endl;
	//Son:: 表示通过Son这个类名来访问Base作用域下面的m_a成员变量。
}
//静态成员函数也是一样的道理
int main()
{
	test01();
	system("pause");
	return 0;
}
