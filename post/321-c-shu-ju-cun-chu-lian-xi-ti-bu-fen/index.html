C语言里面的++运算符号的使用

int main()
{
	int a = 5;
	int b = 5;
	int x = ++a;//识别，这里属于前置++，先对变量a完成自增+1的操作，然后再赋值给变量x!
	int y = b++;//后置++，先用，用完后再++，先把b原本的值作为b++的结果赋值给y，然后再对内存中的b进行自增+1
	return 0;
}

i++

{
    int temp = i; // 1. 产生临时副本
    i = i + 1;    // 2. 增加原始变量的值 (副作用)
    return temp;  // 3. 返回副本给表达式
}

指针变量和++运算符的一些经典组合

关于这一部分的内容，我们要注意运算符的优先级和结合性，当优先级相同的时候要考虑结合性！
这一部分的内容要注意是修改的值还是地址！
比如：修改的值：( * ptr)++，先对（ * ptr）进行操作，得到ptr当前指向的内容，并产生当前指针的一个副本作为结果返回，然后再对（ptr）进行++的操作！
修改的是地址： ptr++,这个式子等同于 (ptr++)，那么先执行ptr++，生成ptr当前值的副本来返回结果，和结合，得到当前ptr指向的内容，然后再改变ptr，对其++，使其指向下一个内容！

C语言中的赋值运算符=

赋值运算符要求符号左侧是左值，符号右边可以是左值也可以是右值！

什么是左值！

左值（Lvalue） 指的是一个占据内存中可识别位置（即有一个明确的地址）的对象。你可以把它想象成一个容器或者抽屉，而不仅仅是一个数值。

int main()
{
    int a = 10;//b是个左值
    int b = 20;//a是个左值
    //b + 5 是右值： 这是一个临时计算出来的结果，它没有名字，也没有持久的地址。你不能写 b + 5 = 10;，因为编译器不知道要把 10 存到哪里去。
    const int c = 50;//c是一个不可修改的左值
    return 0;
}

一句话总结：
左值是内存中的坑位（有地址），右值是填坑的内容（临时值）。在 C 语言里，如果你能对一个东西用 & 取地址，它通常就是一个左值。

原码->反码->补码
原码、反码、补码复习：
在C语言（以及大多数现代计算机架构）中，原码、反码、补码是机器存储和运算整数的三种不同编码方式
原码是给人看的，可直接按位求和计算的，补码是整数数据在计算机里面的一个实际存储方式，同时也是为了方便计算机计算！

char ：-128 ~ 127 
因为补码中 1000 0000 被规定为 -128，它有效解决了 -0 的浪费问题，比原码多表示一个数。
unsigned char : 0~255

无符号整数数据类型的原反补码

  • 无符号数(unsigned)在计算机眼里没有符号位。
  • 无符号数的原码、反码、补码全部相同。

有符号整数数据类型的原反补码

有符号数据类型也会存放正数的数值， char 类型的范围是 -128~127 。
如果是正数，原反补相同；如果是负数，才需要执行取反加1。

负数的原码反码补码情况

  • 原码：最高位是符号位，仅仅表示符号，不为有值属性位数（高位是0，说明数据是正数，高位是1，说明数据是负数）
  • 反码：原码符号位不变，其余按位取反，即得到了反码。
  • 补码：在反码的基础上加1即可。

整型提升


整型提升（Integer Promotion）的逻辑其实是：当 CPU 发现你给它的数据类型“太短”（位宽小于 int），它在处理这个数据的一瞬间，会先把它“拉长”到 int 的长度。
整型提升的本质：
只要数据类型的大小 小于 int，在 运算、比较、传参 的那一刻，它就会按照符号位自动扩展为 int。

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
//**整型提升的规则：**
//有符号的类型，看符号位，是0就补0，是1就补1。
//无符号的类型，直接补零就完了！！！
int main()
{
	unsigned char a = 200;
	unsigned char b = 100;
	unsigned char c = 0;
	c = a + b;
	printf("%d %d", a + b, c);//二者的差别还是挺大的，a+b发生了整型提升，但是没有进行截断，而c=a+b，进行了Integer promotion，但是要放到只能容纳八位的c里面，所以要截断一下
	return 0;
}
//200的二进制表示
//00000000 00000000 00000000 1100 1000
//放到a里面显然放不下，所以要截断，截断后
//1100 1000
//来看100
//00000000 00000000 00000000 0110 0100
//放到b里面，截断
//0110 0100

//计算a+b，输出格式为%d所以要进行整型提升
//由于都是无符号类型，直接补零就完了
//200
//00000000 00000000 00000000 1100 1000
//100
//00000000 00000000 00000000 0110 0100
//相加：
//00000000 00000000 00000001 0010 1100
//值为300


//计算c
//c = a+b
//a数据整型提升后
//00000000 00000000 00000000 1100 1000
//b数据整型提升后
//00000000 00000000 00000000 0110 0100
//二进制相加后：
//00000000 00000000 00000001 0010 1100

//截断后
//0010 1100
