程序的内存模型

未执行程序前分为代码区和全局区！

代码区

全局区

全局区存放全局变量和静态变量。（static修饰的变量是静态变量）
全局变量还包含了常量区、字符串常量和其他常量也存放在此。（包含const修饰的全局变量）
该区域的数据在程序结束后由操作系统释放。

栈区

栈区存放

1. 局部变量
2. 形式参数

堆区

  1. 由程序员管理开辟和释放
  2. 堆区数据利用new关键字进行开辟内存

new -- delete

用法格式1：数据类型* 指针 = new 数据类型;
用法格式2：数据类型* 指针 = new 数据类型（值）;//申请内存的时候直接初始化

### 数组
数据类型* 指针 = new 数据类型[元素个数];

new 和 malloc

int* p = (int*)malloc(sizeof(int));//需要类型转换，也需要自己求数据类型的字节数
*p = 100;

free(p);

int* p = new int;
*p = 100;

delete p;

用new申请动态数组

int main()
{
	int number = 0;
	cout << "请输入期望数组元素的个数：" << endl;
	cin >> number;
	int* arr = new int[number];
	for (int i = 0; i < number; i++)
	{
		cout << "请输入数组元素arr["<< i<<"]的值：";
		cin >> arr[i];
	}
	//结果打印输出
	for (int i = 0; i < number; i++)
	{
		cout << arr[i] << endl;
	}
	delete[] arr;//对于为数组申请内存空间的时候要加上[]，向告诉编译器我要申请数组空间，和new一个数组一样
	system("pause");
	return 0;
}

引用-reference

格式：数据类型& 引用名 = 变量名;
作用：给变量起别名。
注意事项：

  1. 使用引用时必须要初始化
  2. 引用不可以更改。

引用可以作为函数参数

引用作为函数参数
void swap(int& a,int& b)
{
	int tmp = a;
	a = b;
	b = tmp;
}
int main()
{
	int a_main = 10;
	int b_main = 20;
	cout << "交换前：" << endl;
	cout << "a_main:" << a_main << endl;
	cout << "b_main:" << b_main << endl;
	swap(a_main, b_main);
    ////////////////////
	cout << "交换后：" << endl;
	cout << "a_main:" << a_main << endl;
	cout << "b_main:" << b_main << endl;
	system("pause");
	return 0;
}

引用可以可以作为参数返回值

int& test01()
{
	static int a = 10;//用static修饰变量a，a就是静态变量了，存放在全局区上面
	return a;
}
int main()
{
	int& ref = test01();
	cout << "ref = " << ref << endl;
	cout << "ref = " << ref << endl;
	test01() = 1000;//函数的调用可以作为左值
	cout << "ref = " << ref << endl;
	cout << "ref = " << ref << endl;
	system("pause");
	return 0;
}

引用的本质是指针常量

int& a  = b;
//等同于
int * const  a = &b;
//a就是一个指针常量，由于由const，所以不可以过改变a的指向对象

int &a = 10;//不合法
//因为 10 是一个临时值（右值），而普通的 int& 引用只能绑定到一个可以被修改、具有持久存储的对象（左值）。

普通引用 int& → 主要绑定“变量”；不能直接绑定“常量/临时值”。
const int& a = 10; // ✅ 合法
这里 const int& 可以绑定临时值，编译器会延长这个临时对象的生命周期。

函数高级

默认参数

  1. 如果某个位置的参数有默认值，那么这个位置往后，从左往右，必须有默认值。
void fun1(int a = 10,int b)
{
    //错误写法
}
void fun2(int a ,int b = 10,int c = 20)
{
    //正确写法
}
  1. 如果函数声明有默认值，函数实现的时候就不能有默认参数，反过来也一样。

函数重载（重复的重）

函数重载就是：
同一个函数名，可以根据不同的参数列表（参数个数或类型）定义多个版本，调用时由编译器自动选择对应的函数。
作用：函数名可以相同，提高复用性
函数之间有相同的地方，但是一定要有不同的地方，要让编译器来区分函数之间的区别，从而选择调用哪个函数。
函数重载的满足条件：

  • 同一个作用域下
  • 函数名称相同
  • 函数参数类型不同或者是个数不同 或者是顺序不同
    注意：函数的返回值不可以作为函数重载的条件。

函数重载的注意事项

  1. 引用作为重载条件
void func(int &a)
{
    cout <<"func(int &a)调用"<<endl;
}
void func(const int &a)
{
    cout <<"func(const int &a)调用"<<endl;
}
  1. 函数重载碰到函数默认参数
