C语言进阶-动态内存部分（非常重要）

2026-05-14 4 min read # C语言学习笔记

为什么我要学习动态内存部分？

答：
1.
真实的数据需要，显示中的数据几乎是‘动态的’、用户输入多少不知道、文件多大不知道、图片大小不知道、学生人数不知道，开发程序时不可能提前写死这些东西 int num_of_student[10000000000000]，提前写死太小了不够，太大了又浪费，所以要按需分配内存空间，因此动态划分必不可少。
2. 数据结构需要，链表、树、哈希表、图这些东西的数据量都不是固定的，因此需要动态划分内存。
3. 嵌入式岗位刚需，动态内存管理的能力其实就是考研程序员控制资源的能力(对底层的熟悉程度)，嵌入式的设备内存空间有限，必须要程序员精打细算。
4. 学习程序是如何管理内存和数据的，加深自己对程序的理解深度，理解程序为什么“崩”和“卡”，写出健壮的代码

动态内存管理函数（在Heap里面操作）

malloc和free(向堆区申请和释放内存空间)

malloc（向操作系统申请一处堆区的内存空间，仅仅申请，未进行初始化）

函数原型：void *malloc( size_t size );
函数作用：在堆区申请一块指定大小的连续内存空间，并返回这块内存的起始地址。
Parameters：一共要申请的字节大小。
int* p = (int*)malloc(n*sizeof(int));
Return_Value:

  • 成功时，返回指向函数分配的内存块的指针。此指针的类型始终为 void*，可以强制转换为所需的数据 指针类型以便解引用。
  • 如果函数分配请求的内存块失败，则返回空指针(NULL)。
    注意：使用malloc时一定要对其返回值进行检查。
用法实例
int* p = (int*)malloc(10*sizeof(int));//申请10个int大小的空间，返回空间起始地址
//这里最好写sizeof(int),而不是sizeof(4)，在不同的环境下int的字节大小可能不一样的。

int main()
{
	int* p = (int*)malloc(10*sizeof(int));
	if (p == NULL)//申请失败的情况
	{
		printf("%s\n", strerror(errno));//打印错误信息
		return 1;
	}
	int i = 0;
	for ( i = 0; i <10; i++)
	{
		p[i] = i;//对申请的空间进行初始化，不然里面都是垃圾值
	}
	for ( i = 0; i < 10; i++)
	{
		printf("%d ", p[i]);
	}
	free(p);//释放掉这些空间
	p = NULL;
	return 0;
}

free函数（释放和回收申请的动态内存空间）

函数原型： void free(void* ptr)
**函数作用：**将malloc申请的堆内存还给操作系统。

  • 如果参数 ptr 指向的空间不是动态开辟的，那free函数的行为是未定义的。
  • 如果参数 ptr 是NULL指针，则函数什么事都不做。
    为什么要用free将内存还给操作系统？
    malloc 申请的内存不会自动释放，如果程序一直运行，那么申请的空间一直被占用，会导致资源浪费。

calloc函数（动态开辟内存空间函数）

realloc函数（动态调整）

函数原型： void* realloc(void* ptr,size_t size);
函数作用：
重新申请一块内存空间。
参数：

  • ptr，原先通过malloc、calloc或realloc申请的一块内存空间。
  • size 新的内存块空间，单位是Byte。
    Return Value：一个指向重新分配的内存块的指针，它可以是与 ptr 相同，也可能是一个新的地址。
