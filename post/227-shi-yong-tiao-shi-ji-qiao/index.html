2.27-实用调试技巧

2026-02-27 3 min read # C语言学习笔记

调试

调试（英语：Debugging / Debug），又称除错，是发现和减少计算机程序或电子仪器设备中程序
错误的一个过程。

基本步骤

  • 发现程序错误的存在
  • 以隔离、消除等方式对错误进行定位
  • 确定错误产生的原因
  • 提出纠正错误的解决办法
  • 对程序错误予以改正，重新测试
    拒绝迷信式调试（不动脑去思考错误缘由，仅仅对着代码瞎胡改）

debug 与 release

Debug 通常称为调试版本，它包含调试信息，并且不作任何优化，便于程序员调试程序。
Release 称为发布版本，它往往是进行了各种优化，使得程序在代码大小和运行速度上都是最优的。
简单来说，一个是给程序员看的（debug版本），方便调试代码，一个是让用户用的（release版本），让用户用着舒服！

关于调试的一些知识、快捷键与调试技巧

断点：断点是 C 语言调试中给程序设置的执行暂停点，运行到断点行程序暂停，方便查看实时状态！

可以把断点理解为一个飞雷神标记，我们在一行代码中留下飞雷神标记（断点），发动忍术（按下F5）直接来到标记位置（断点位置），以此来查看此时程序的情况！
也可以添加触发条件（i==3）
水门到标记处后，能立刻发起攻击、救人，完成操作后再离开 → 程序停在断点（标记）处时，你能查看变量 / 指针值、修改数据、单步执行，完成调试操作后，再让程序继续运行（相当于 “离开标记处”）。

快捷键

  • F5
    启动调试，经常用来直接跳到下一个断点处。
  • F9
    创建断点和取消断点
    断点的重要作用，可以在程序的任意位置设置断点。
    这样就可以使得程序在想要的位置随意停止执行，继而一步步执行下去。
  • F10（开启调试功能）
    逐过程，通常用来处理一个过程，一个过程可以是一次函数调用，或者是一条语句，F10会把函数调用语句直接执行完，没有进入函数内部，也没有识别函数的变量。
  • F11
    逐语句，就是每次都执行一条语句，但是这个快捷键可以使我们的执行逻辑进入函数内部（这是最
    长用的）。
  • CTRL + F5（开启运行代码）
    开始执行不调试，如果你想让程序直接运行起来而不调试就可以直接使用。
