结构体内存对齐

这部分知识主要探讨一下结构体的内存大小极其计算方法！

怎么计算结构体的内存大小

先看一段代码：

struct S1
{
	char c1;
	int i;
	char c2;
};
int main()
{
	printf("%d\n", sizeof(struct S1));
	return 0;
}

没学过这个知识前，我会很自然的认为struct S1这个自定义结构体类型的字节大小是(1+4+1)个Bytes，实际上不是这样的。

😀结构体内存对齐的规则


我们自定义一中结构体数据类型，是为了方便描述一些复制对象的，既然我们创建了这种数据类型，肯定要拿去创建变量，创建变量就要在内存中给这个变量划分存储空间的，肯定要先找到一个起始位置的。

结构体变量偏移量：偏移量就是看结构体变量的起始地址以后的每一块内存空间的起始位置和结构体变量的起始地址中间有几个内存空间，有2个内存空间，那么该内存空间相对于结构体变量的起始地址的偏移量就是2。

struct S1
{
	char c1;//
	int i;
	char c2;
};
//即使是相同的结构体成员列表，但是包含它们的结构体类型的内存大小页可能不一样，
//原因是由于成员列表顺序不一样，所以它们的对齐方式不一样，所以Compiler的处理方式也就不一样
struct S2
{
	char c1;
	char c2;
	int i;
};

int main()
{
	struct S1 s1;
	struct S2 s2;
	printf("%d\n", sizeof(struct S1));//12个字节大小
    printf("%d\n", sizeof(struct S2));//8个字节大小
	return 0;
}

结构体传参

结构体传参依旧分为传值和传址这两种方式。

#include<stdio.h>
#include<stddef.h>
struct stu
{
	int data[1000];
	int num;
};

void print1(struct stu s)
{
	printf("传值方式打印结构体数据：");
	int i = 0;
	for (i = 0; i < 3; i++)
	{
		printf("%d ", s.data[i]);
	}
	printf("%d\n", s.num);
}

void print2(struct stu* ps)
{
	printf("传址方式打印结构体数据：");
	int i = 0;
	for (i = 0; i < 3; i++)
	{
		printf("%d ", ps->data[i]);
	}
	printf("%d\n", ps->num);
}
int main()
{
	struct stu s = { {1,2,3},100 };
	print1(s);//传值
	print2(&s);//传址
	return 0;
}
