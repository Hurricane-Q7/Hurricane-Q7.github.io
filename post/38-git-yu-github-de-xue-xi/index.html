3.8-git与GitHub的学习

2026-03-08 6 min read # git学习

Github重要程度：⭐️⭐️⭐️⭐️

Github是一个全球最大的开源社区，里面有很多人分享的各个方面学习资料、个人项目、以及一些世界级开源项目、以及一些开源工具的等等。
对于我来说，Github以后是我对外的窗口，我要把我四年做的东西放到Github上，这样可以方便面试官快速了解水平功底，也方便阅览个人项目，所以Github对我来说就像是一个专属于程序员的自媒体账号，所以四年里我要用心打磨这个对外的窗口。
所以，一个亮眼的Github账户对于我以后面试来说是一个巨大的加分项。

我能用Github来做什么？

学习

  1. 找学习资料（编程、数学、英语等等），非常多的学习资料。
  2. 找编程项目学习，Github上面有很多开源的优质项目，我可以借鉴大佬们写的代码，看看别人怎么写注释的，逻辑是怎么拆解的，项目结构是什么？
  3. 找开源库直接用，直接调用别人写好的库，拿来用就好。

练手 & 做项目 ：搭建个人作品集（面向求职）

Github本质上就是程序员的个人简历，就是给别人看的！

  1. 上传个人写的一切东西（代码、项目……）
    上传Github时的好习惯养成：
  2. 编写好readme文档（用Markdown）
  3. 过滤大文件
  4. commit记录要干净
  5. 仓库命名要简单明了直观！

版本控制：核心功能

  1. 随时保存版本信息，写错查看提交记录，一键回退
  2. 多人协作。

求职：最关键

  1. 简历加分
  2. 面试可以聊项目

玩Github前最好会两个工具

Git (版本管理神器)

可以通过指令，把在本地的项目和代码推送到Github上。

Markdown语法

为了写Readme文档用的，用markdown写简单高效。
Readme文档一定要写好，方便别人快速了解项目功能。
readme要点:

  1. 项目简介
  2. 功能点
  3. 技术栈
  4. 效果图
  5. 项目结构
  6. tool
  7. 改进方向

git学习

git的三个工作区域

工作区->暂存区->git本地厂库

Git基本指令操作

增删改查（touch/rm/vim/cat）

1. git init //在本地目录下初始化厂库，创建一个git本地厂库
2. touch 文件名.文件扩展名//基础命令，创建文件
3. mkdir 文件夹名字//创建文件夹
4. git add 文件 (git add . 一键打包)//添加到暂存区
5. git commit -m '提交描述';//将当前目录下文件从暂存区添加到git本地厂库，每一次改动都要提交来保存信息
6. cat 文件名//查看文件内容

修改文件

1. vim/vi 文件 //修改文件，vim是Linux上的一个编辑器
2. git add 文件//添加到暂存区
3. git commit -m '更改信息'//保存

删除文件

1. rm -rf 文件
2. git add 文件
3. git -m commit '更改信息'//

Git 远程管理（重点）

作用：备份，实现代码共享集中化管理，方便他人查看

通过Git来从本地推送代码

1. 在本地目录下输入"git init"初始化仓库;
2. git remote add "远程仓库name" "远程仓库地址"//远程连接仓库，方便随后git push代码
3. 在当前目录下创建文件、删除、修改等等;
4. git add 文件名
5. git commit -m "提交信息"//保存
6. git push -u 仓库名 分支名//-u  绑定关系（首次推送必须加），origin GitHub仓库别名 
//第一次用上面的推送指令 以后直接 git push即可

通过git修改远程厂库代码

在GitHub上想要修改别人代码要先fork厂库到自己的账号里，然后修改，改完后发起Pull Request！
那么本地git里，我们要先clone 一个仓库到本地，clone之前不需要git init ，会自动创建创建！

方法一：
1. 获得该厂库的地址
2. 找到一个目录下 使用"git clone 厂库地址",不需要git init
3. 对该项目进行增删改查操作(touch/rm/vim/cat 文件)
4. git commit -m '描述'
5. 最后直接git push即可

分支名称错误


搭建步骤

  1. 进入项目主页，点击settings
  2. 在settings页面，点击【Launch automatic page generator】来自动生成主题页面

git中关于分支的命令

1. git branch //查看当前所有分支，空仓库没 commit 之前，啥也看不到！
2. git branch "分支名称" //创建一个分支
3. git checkout "分支名称"//切换到要切换到的分支
4. git checkout -b "分支名称"//创建一个new分支，同时切换到该分支！
//不能删除当前分支，只能删除其他分支，要想删除当前分支，先切换到别的分支
5. git branch -d b1//删除分支,需要一些检查
6. git branch -D b1//不做任何检查，强制删除
7. git branch -m "当前分支名" "目标分支名"//(git branch -m master main将master改为main)
