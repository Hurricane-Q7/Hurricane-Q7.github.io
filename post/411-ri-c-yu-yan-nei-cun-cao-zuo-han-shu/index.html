memcpy函数

函数模型：

void * memcpy (void * destination,const void * source，size_t num);

函数作用：

Copy block of memory，内存块拷贝函数

  • 函数memcpy从source的位置开始向后复制num个字节的数据到destination的内存位置。
  • 这个函数在遇到‘0'的时候并不会停下来。
  • 如果source和destination有任何的重叠，复制的结果都是未定义的。
  • 也就是说memcpy函数是不用来处理重叠数据之间的内存拷贝滴！

函数参数：

destination

Pointer to the destination array where the content is to be copied, type-casted to a pointer of type void*.

source

Pointer to the source of data to be copied, type-casted to a pointer of type const void*.

num

这个num就是你要拷贝的数据的字节大小！
Number of bytes to copy.
size_t is an unsigned integral type.

#include <stdio.h>
#include <string.h>

struct {
  char name[40];
  int age;
} person, person_copy;

int main ()
{
  char myname[] = "Pierre de Fermat";

  /* using memcpy to copy string: */
  memcpy ( person.name, myname, strlen(myname)+1 );
  person.age = 46;

  /* using memcpy to copy structure: */
  memcpy ( &person_copy, &person, sizeof(person) );

  printf ("person_copy: %s, %d \n", person_copy.name, person_copy.age );

  return 0;
}

memset（内存空间填充函数）

头文件：<string.h>
函数介绍：
Fill block of memory.
Sets the first num bytes of the block of memory pointed by ptr to the specified value.填充由指向特定值的指针指向内存块的前num个字节

函数模型：

memset是以字节为单位来按value来初始化内容的！
void * memset ( void * ptr, int value, size_t num );

我的参数

num:将要被set特定值的字节个数！

Return Value

ptr is returned!

int main()
{
	int arr[10] = { 0 };
	memset(arr, 1, sizeof(arr));//这里想把数组的内容全部初始化为1
    //memset是按字节为单位来初始化内容的，这里把40个字节的内容全部变成1
    //二进制表示
    //0原来的二进制：
    //00000000 00000000 00000000 00000000
    //以字节为单位变动后：
    //00000001 00000001 00000001 00000001（16843009）
	int i = 0;
	for (i = 0; i < 10; i++)
	{
		printf("%d \n", arr[i]);//组合4个字节为一个int型数据
	}
	return 0;
}
//发现结果没有符合预期：
//16843009
//16843009

为什么可以通过memset将数组内容初始化0或-1？
整型数据在内存中是按补码进行存储的。
-1的补码是：
11111111 11111111 11111111 11111111
然后把每一个字节的内容变成-1的补码内容，最后在组合输出！
int main()
{
    int arr[10]={0};
    memset(arr,-1,sizeof(arr));
    int i = 0;
    for(i=0;i<10;i++)
    {
        printf("%d ",arr[i]);
    }
}
归根结底，还是-1与0的补码的特殊性（都是0或1）！
