虚拟内存空间-Heap和Stack（动态内存空间）

2026-05-19 2 min read # C语言学习笔记


栈（stack）

核心特点：

  • 后进先出，先进后出（last in ,first out）
  • 操作系统自己自动管理
    两个动作：
  • 入栈（Push）将数据压入栈顶
  • 出栈（Pop）:将栈顶的数据弹出释放。

栈里面放的什么？

  1. 局部变量，函数内部定义的非静态变量。
  2. 函数参数：传给函数的形参
  3. 函数的返回地址：记录当前函数执行完后，程序应该跳回哪一行代码继续执行。
  4. 函数栈帧.[1]

栈空间的自动管理机制（核心机制）

与需要程序员手动申请、手动释放的“堆空间（Heap）”不同，栈空间的分配和释放完全由编译器和CPU 自动控制，不需要你写任何代码去管理。

堆（heap）

堆的介绍：

  1. 程序运行时，由程序员主动申请、主动释放的一块动态内存区域。（程序员自己管理，自己释放）
  2. 堆内存是动态内存空间的一部分，是动态规划内存时的主战场（在堆上申请和释放内存），
    堆的核心特点：
  3. 大小运行时决定（最大特点）
  4. 生命周期由程序员自己控制
  5. 不会自动释放，需要手动free。
  6. 通过指针访问。
int main()
{
    int n = 0;
    scnaf("%d",&n);
    int* p = (int*)malloc(n*sizeof(int));
    //程序运行前，更本不知道n时多少，所以也不知道程序员想要申请多大的内存空间。
    //当用户输入n之后，才知道n是多少。
    //想要访问这段内存空间，直接用指针访问就可以了。
    //这段空间需要手动释放。

    return 0;
}
