4.5-C语言-qsort函数与回调函数

2026-04-05 2 min read # C语言学习笔记

qsort函数

头文件<stdlib.h>

qsort函数是一个排序函数（默认是升序的），本质上是快速排序！
函数模型：
void qsort( void *base, size_t num, size_t width, int (*compare )(const void *elem1, const void *elem2 ) );
可见这个函数的返回值是void，并且有4个Parameters，分别是base(要排序的首元素起始地址)，num（要排序的数字个数），width（每个待排序元素的字节大小）
compare，这是一个函数指针变量，它的类型是int (* )(const void* elem 1,const void * elem 2),指向的是一个返回值是int 、参数是const void * 型的一个函数！
qsort函数可以比较多种类型的数据，但是需要我们自己提前配置好多种数据类型之间的比较函数，然后把这个比较函数的地址给传过去！！！

回调函数

回调函数就是一个通过函数指针调用的函数。如果你把函数的指针（地址）作为参数传递给另一个
函数，当这个指针被用来调用其所指向的函数时，我们就说这是回调函数。回调函数不是由该函数
的实现方直接调用，而是在特定的事件或条件发生时由另外的一方调用的，用于对该事件或条件进
行响应。
用qsort函数来排序数据时，需要一个内嵌比较函数，而qsort通过这个比较函数的指针来间接访问比较函数，这个比较函数就是回调函数！
