2.15日-C语言-指针基础、指针类型的意义

2026-02-13 5 min read # C语言学习笔记

指针

首先理解指针的两个要点

内存中有很多个小的内存单元，每个内存单元有1Byte。

  1. 指针是内存中一个最小单元的编号，也就是地址。
  2. 平时口头上说的指针，通常指的是指针变量，指针变量是一个变量，用来存放内存地址的变量。
int a = 10;
int* pa = &a;//pa里面放的是a的起始地址
//解引用*pa时，编译器会从起始地址开始，连续读取 4 个字节，拼接成完整的int值；
//指针运算pa+1时，地址会直接 + 4 字节（跳到下一个 int 的起始地址），而不是 + 1 字节

这里我们就明白:

  1. 在32位的机器上，地址是32个0或者1组成二进制序列，那地址就得用4byte的空间来存储，所以一个指针变量的大小就应该是4byte。
  2. 那如果在64位机器上，如果有64个地址线，那一个指针变量的大小是8byte，才能存放一个地址，所以在64位机器上一个指针变量大小就是8byte。

指针和指针类型

指针类型的两条意义

结论1： 指针类型决定了指针在被解引用的时候访问几个字节，有多大的权限（能操作几个字节）
比如，int*的指针变量，被解引用时可以访问4个字节,char *类型的指针变量被解引用的时候可以访问1个字节。

int main()
{//x86
    int a = 0x11223344;
    char* pc = (char*)&a;
    *pc = 0;//经过调试，发现仅仅更改了1byte的数据：0x00CFFC50  00 33 22 11（0x代表16进制的表现形式,00 33 22 11 ，一共8位，两位一字节）
    return 0;
}
int main()
{
        int a = 0x11223344;
        int* pc= &a;
        *pc = 0;//此时a在内存中是0x 00 00 00 00，一次性被操作了4byte
        return 0;
    
}

结论2： 指针类型决定了加减整数的时候运算步长（几个Bytes）。
指针类型决定“走一步跨多远”。

int main()
{
	int n = 10;
	int* pa = &n;
	char* pc = (char* ) & n;
	printf("%p\n", pa);
	printf("%p\n", pa + 1);//跳过1个int型，也就是4byte，也可以理解位跳过4个内存单元，每个内存单元对应一个地址
	printf("%p\n", pc);
	printf("%p\n", pc+1);//跳过1个char型，也就是1byte
	return 0;
}

地址+1，本质上是地址+sizeof(地址指向的数据类型)。

int main()
{
	int arr[3] = { 10,20,30 };
	int* p = arr;
	printf("%p\n", p);
	printf("%p\n", p+1);//地址+1可不是真的地址加一
	printf("%p\n", p+2);//而是，地址+sizeof(指向的数据类型)
	return 0;
}

注意：即使两个指针变量解引用操作时都可以访问相同的字节、+-时改变的步长一样也不能通用，因为二者指向的对象在内存中的存储方式不一样的！

指针变量与const关键字

const可以用来修饰指针变量，一共有如下三种常见情况,每一种情况都有不同的限制！

第一种：
int a = 10;
const int* p = &a;//此时const限制*p,即不能通过对p解引用操作来间接更改p所指向对象的内容，比如：*p = 20。
第二种：
int a  = 10;
int* const p = &a;//p指向的对象是可以用过p来改变的，但是不能修改p指针变量的值，也就是地址，比如：p = &b。
第三种：
int a = 10;
const int*  const  p = &a;//上面两种情况都不行了，哈哈哈！

总结

  • const在 * 左边 → 指针指向的内容不可改，指针变量本身可改；
  • const在 * 右边 → 指针变量本身不可改，指向的内容可通过解引用改；
  • const在 * 两边 → 内容和指针都不可改；
    核心：const修饰 “离它近的那个东西”（左边修饰类型 / 内容，右边修饰指针变量）。
例子1：
#include <stdio.h>
int main() {
    int a = 10, b = 20;
    const int* p = &a;

    // 合法：指针本身可以改指向（p从指向a变成指向b）
    p = &b;
    printf("*p = %d\n", *p); // 输出：20

    // 非法：不能通过p修改指向的内容（编译报错）
    // *p = 30; // 错误：assignment of read-only location '*p'

    // 注意：变量a本身不是const，直接修改a是合法的
    a = 30;
    printf("a = %d\n", a); // 输出：30
    return 0;
}
