关于整型提升的练习

位权展开法，天生就是给原码用的。
补码是给计算机存、算用的，不是给你手动按权展开用的。
二进制转十进制，用位权求和时：
无符号数：直接算
有符号正数：直接算
有符号负数：必须先变回原码，再用原码算
整型提升的规则：
有符号的类型，看符号位，是0就补0，是1就补1。
无符号的类型，直接补零就完了！！！

参与运算的数据达不到一个整型大小要整型提升！！！
int main()
{
    char a = -1;
    //将整型数据存放到char类型里面，32bit放到8bit里面，显然放不下，因此要先截断补码，截断后再去存放！
    //-1的原码
    //10000000 00000000 00000000 00000001
    //反码：（原码符号位不变，其余取反）
    //11111111 11111111 11111111 11111110
    //补码：（反码加1）
    //11111111 11111111 11111111 11111111
    //截断补码（内存中存放的是补码）：1111 1111
    signed char b = -1;
    unsigned char c = -1;
    printf("%d %d %d",a,b,c);// 结果是-1 -1 255
    //原因分析：%d是打印有符号的整型数据，一个整型的数据大小是4byte,而char类型只有1byte，所以在输出的时候要进行整型提升！
    //比如unsigned char c = -1;无符号整型数据类型，没有负数的概念，
    //这里-1的补码1111 1111的符号位失效了，变成表示值得二进制位了，编译器把它认为是个正数
    //-1的原码：
//10000000 00000000 00000000 00000001
//-1的反码：
//11111111 11111111 11111111 11111110
//-1的补码：
//11111111 11111111 11111111 11111111
//截断补码后：
// 11111111
// 整型提升补零
// 00000000 00000000 00000000 11111111   //正数三码相同，255
}

%d既可以打印有符号和无符号，但是%u只能打印无符号;

int main()
{
    char a =-128 ;//有没有符号不是看数字面前带不带符号，而是看数据类型定义标识符，char实际上就是有符号的
    printf("%u\n",a);//只打印无符号的数据
    printf("%d\n",a);//可以打印无符号类型数据也可以有符号类型数据
    return 0;

}

int main()
{
	char a[10000];//char类型的数据范围是-128~127
	//
	int i;
	for (i = 0; i < 1000; i++)
	{
		a[i] = -1 - i;

	}
	//-1 -2 -3 -4 ……-128 127 126 ……1 0
	printf("%d", strlen(a));//结果是255，strlen统计\0之前的字符个数，\0就是0
	return 0;
}

学习总结

最近主要学习了整型数据在内存中是如何存放的（大小端的存放方法，字节为单位），大端存放就是正序，小端存放就是倒序存放，又复习了原码、反码、补码三者的关系，正数的三码相同，负数的原码、反码、补码各不相同，需要进行转换，一个负数原码变成补码需要取反加1，而一个负数的补码变成原码也可以直接取反再加1！
//-1原码
//1000 0001
//反码
//1111 1110
//补码：反码加一
//1111 1111
//取反加一变原码
//1000 0001
又深化了自己对原码与补码的理解，数据在内存中存放的是补码，而原码是给人看的，补码是给计算机算的
，如果想要按照权位求和的话，是需要一个数据的原码的（正数除外，三码相同）。
又复习了整型提升的知识，当有些数据参与运算时达不到一个最小int型的运算精度，此时就会发生整型提升，对数据的高位补（0/1），无符号数据直接补0，有符号数据看高位是什么，是0补零，是1补1！
还有整型提升时不是看数据带不带符号，而是看数据类型是有符号的还是无符号的，也不是看格式控制符号（signed/unsigned）!
