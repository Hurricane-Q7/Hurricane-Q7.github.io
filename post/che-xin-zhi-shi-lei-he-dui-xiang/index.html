C++学习阶段（二）-面向对象-封装

2026-08-20 11 min read

类和对象

C++面向对象的三大特征：封装、继承、多态

封装(添加属性和行为)

意义：

  1. 将属性和行为作为一个整体，表现生活中的事物。
  2. 将属性和行为加以权限控制。
语法：class 类名
{
    访问权限：
    属性；
    行为；//一般是函数，处理数据，执行动作
}

类中的属性和行为 我们统一称为成员
属性 ：成员属性 成员变量
行为 成员函数 成员方法

class student
{
public:
	//设计学生类属性
	string stu_name;
	string stu_ID;
	//设计行为
	void display_stu_info()
	{
		cout << "学生姓名：" << stu_name << endl;
		cout << "学生学号：" << stu_ID << endl;
	}

};
int main()
{
	student s1;
	s1.stu_name = "张三";
	s1.stu_ID = "123456789";
	s1.display_stu_info();
	system("pause");
	return 0;
}

封装意义二-权限


三种
- 公共权限：public权限 成员 类内可以访问 类外可以访问
- 保护权限：protected权限 成员 类内可以访问 类外不可以访问
- 私有权限 private权限 成员 类内可以访问 类外不可以访问  
class person
{
public: //公共权限
	string name;
protected://保护权限
	string m_Car;
private://私有权限
	string m_password;
public:
	void func()
	{
		m_password = "张三";
		m_Car = "拖拉机";
		m_password = 123456;

	}
};
int main()
{
	person p;
	p.name = "李四";
	p.m_Car = "奔驰";//保护权限：类内可以访问，类外不可以访问
	p.m_password = 88888;
	system("pause");
	return 0;
}

C++中的class 和 struct关键字的区别

class 和 struct 都可以创建一个类
**区别：**class创建的类的权限默认是Private，而struct默认是public。

成员属性设置为私有

优点1：将所有成员属性设置为私有，可以自己控制读写权限。
优点2：对于读写权限，我们可以检测数据的有效性。

对象特性学习

构造函数（初始化）和析构函数（清理数据）

构造函数语法:类名(){}
1.构造函数，没有返回值也不写void
2.函数名称与类名相同
3.构造函数可以有参数，因此可以发生重载
4.程序在调用对象时候会自动调用构造函数，无须手动调用,而且只会调用一次（初始化操作 ）

析构函数语法:~类名(){}
1.析构函数，没有返回值也不写void
2.函数名称与类名相同,在名称前加上符号~
3.析构函数不可以有参数，因此不可以发生重载
4.程序在对象销毁前会自动调用析构，无须手动调用,而且只会调用一次

构造函数的分类及其调用

两种分类方式：

  • 按参数分类：有参构造和无参构造 （无参又称为默认构造函数）
  • 按类型分类：普通构造和拷贝构造函数
    三种调用方式：
  • 括号法
  • 显示法
  • 隐式转换法
1. 括号法
Person p1;//默认构造函数调用，不要加()
Person p2(10);//有参构造函数调用
Person p3(p2);//拷贝构造函数调用
	2. 显示法
	Person p1;
	Person p2 = Person(10);
	Person p3 = Person(p2);	
    3. 隐式转化法
Person p4 = 10;//相当于写了 Person p4 = Person(10)

拷贝构造函数的调用时机

  1. 使用一个已经创建完毕的对象来初始化一个新对象（最常见）
  2. 值传递的方式给函数参数传值
  3. 值方式返回局部对象

构造函数的调用规则

默认情况下，c++编译器至少给一个类添加3个函数
1.默认构造函数(无参，函数体为空)
2.默认析构函数(无参，函数体为空)
3.默认拷贝构造函数，对属性进行值拷贝
构造函数调用规则如下：

  • 如果用户定义有参构造函数，C++不在提供默认无参构造，但是会提供默认拷贝构造
  • 如果用户定义拷贝构造函数，C++不会再提供其他构造函数

拷贝构造函数的内部拷贝机制

深拷贝和浅拷贝

**浅拷贝：**简单的赋值拷贝操作。
**深拷贝：**在堆区重新申请空间，进行拷贝操作

如果利用编译器提供的拷贝构造函数，会做浅拷贝操作，这样可能会有潜在的安全隐患问题，要用深拷贝操作来解决。
class Person
{
public:
	Person()
	{
		cout << "默认构造函数调用！" << endl;
	}
	Person(int age, int height)
	{
		p_age = age;
		m_Height = new int (height);
		cout << "有参函数调用" << endl;
	}
	//在系统销毁对象前会调用一次析构函数
	Person(const Person& p)
	{
		p_age = p.p_age;
		//m_Height = p.m_Height;//浅拷贝，简单的赋值操作
		m_Height = new int(*p.m_Height);//重新开辟一块堆内存空间，这就是深拷贝操作
		cout << "拷贝构造函数调用！" << endl;
	}
	~Person()
	{
		if (m_Height != NULL)
		{
			delete m_Height;
			m_Height = NULL;
		}
		cout << "析构函数的调用！" << endl;
	}
	int p_age;
	int* m_Height;
};
void test01()
{
	Person p1(18, 160);
	cout << "p1的年龄为：" << p1.p_age << "身高为：" << *p1.m_Height << endl;
	Person p2(p1);
	//浅拷贝的隐患问题-多次释放一块内存空间
	//在Person类中，没有自定义拷贝构造函数，那么就使用系统提供的拷贝构造函数，采用浅拷贝，实现简单的赋值操作
	//所以，p1和p2中的m_Height指向的同一个内存空间，由于调用两次析构函数，所以会delete两次堆内存空间
	cout << "p2的年龄为：" << p2.p_age << "身高为：" << *p2.m_Height << endl;
}
int main()
{
	test01();
	system("pause");
	return 0;
}

类对象作为类的成员

当类中成员是其他类对象时，我们称为该成员为对象成员
构造的顺序是：先调用对象成员的构造，再调用本类构造。
析构顺序与构造相反。
（先有零件，才能组成一个整体）

静态成员变量（static修饰）

  • 所有对象共享同一份数据（可以通过类名进行访问）
  • 在编译阶段分配内存
  • 类内声明，类外初始化

静态成员函数（static修饰）

  • 所有对象共享同一个函数（所有对象都可以访问该函数，可以通过类名进行访问）
  • 静态成员函数只能访问静态成员变量

C++对象模型和this指针

成员变量和成员函数分开存储

在C++中，类的成员变量和成员函数分开存储，只有静态成员变量才属于类的对象上
规定：空类对象至少占 1 字节，用来保证不同对象拥有不同的地址，大小为零的话，无法区分对象之间的区别，可能会出现地址重复的情况！

this指针的概念

this指针：指向当前正在调用成员函数的对象。
（哪个对象调用成员函数，那么this指针就指向哪个对象）
注意事项：

  • this指针是隐含每一个非静态成员函数内的一种指针。(在函数体内)
  • this指针不需要定义，直接使用即可。

this指针的用途

  1. 指向当前对象（this->age……）
  2. 当形参和成员变量同名时，可用this指针来区分。
class Person
{
    void showAge(int age)
    {
        //age = age;//这样写编译器会认为age就是函数形参的age,并不会修改成员变量age
         this->age = age;//正解，this指针指向当前对象，用指针来访问成员变量，用来区分
    }
int age;
};
  1. 在类的非静态成员函数中返回对象本身，可以使用return *this
class Person
{
public:
	Person(int age)
	{
		this->age = age;
	}
	//第一种写法：返回值
	//Person Person_add_age(Person& p)
	//{
	//	this->age += p.age;//把p的年龄加到当前对象上
	//	return *this;
	//}
	//第一次调用修改的是 p1，之后的链式调用修改的是返回出来的临时副本，临时副本可不是p1，所以 p1 只被修改了一次。
	//第二中写法：返回p1本身的引用
	//Person * const p 
	//Person 返回“复制品”，Person& 返回“原对象的别名”。
	Person& Person_add_age(Person& p)
	{
		this->age += p.age;//把p的年龄加到当前对象上
		return *this;
	}

{
	Person p(10);
	cout << "p年龄：" << p.age << endl;
	Person p1(10);
	//链式编程
	p1.Person_add_age(p).Person_add_age(p).Person_add_age(p);//预期输出:50

}

const修饰成员函数

常函数

  • 成员函数后加const我们称为这个函数为常函数
  • 常函数内不可以修改成员属性(不可以改变成员变量)。
  • 成员属性声明加关键字mutable后，在常函数中依然可以修改。
class Person
{
    //this指针本质上是一个 指针常量（指向的内容不变）eg:int * const p
    //前面在加一个const int * const p，双重限制
    void showPerson() const //showPerson就是一个常函数
{
    this->m_A = 100;//不可以修改
    this->m_B = 100;

}
int m_A;
mutable int m_B;
}

常对象（不可以改变成员属性的值）

  • 声明对象前加const称该对象为常对象。（常对象不可以修改成员属性）
  • 常对象只能调用常函数。（因为普通的成员函数可以修改成员属性）
const Person p;//常对象
