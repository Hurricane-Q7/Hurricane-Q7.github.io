第一题

涉及知识：

  1. 指针类型的意义
  2. 数组指针
  3. 强制类型转换
  4. 数组名和&数组名
程序的结果？
int main()
{
    int a[5] = {1,2,3,4,5};
    int* ptr = (int*)(&a + 1);
    printf("%d,%d",*(a+1),*(ptr-1));
    return 0;
}
答案是：2，5

分析：

直接看ptr ，int * 说明ptr是一个整型指针变量，指向的是一个整型值。
&a，a是数组名，&a表示的是整个数组的地址，表示整个数组的地址，但起始地址也是从数组首元素地址开始，所以（&a）是一个数组指针，指针类型是int (*) [5]，数组元素有5个，每个元素类型是int型，指针类型决定了其+-整数时移动的步长（字节个数），这就像一个int* 变量，+1时，跳过4个字节一样，而这里数组指针类型，+1时直接跳过了一个数组a，跳过了5*4个字节的数据，&a+1前的（int*）是强制类型转换，因为ptr的类型是int * 型的，所以要强制类型转换一下。
紧接着来分析，*(ptr - 1)，ptr是个int * 型指针变量，对其-1，实际上是后退4个字节的数据，所以当前ptr指向的是a[4]，也就是5。
*(a+1)，显而易见，不必多说！

第二题

涉及知识

  1. 计算结构体内存大小（内存对齐）
  2. 指针类型的意义二（加减整数移动或后退移动的字节）
  3. %p与%x格式控制符号
struct test
{
	int Num;//4
	char* pcName;//4
	short sDate;//2
	char cha[2];//2
	short sBa[4];//8
};
//经过计算该结构体的大小20个字节
int main()
{
	printf("%d\n", sizeof(struct test));
	struct test* p = (struct test*)0x100000;
	//可见，p是一个struct test* 类型的指针变量，当前是32位环境下，所以p的大小是4Byte，
	printf("%p\n", p + 0x1);
	//0x1其实就是数字1罢了，只不过这里是用16进制的形式表达的，对指针变量进行加1减1操作，涉及到指针变量的意义，前进或后退指向类型的字节大小
	//p指向的数据类型是struct test的，所以加1的时候，一共要跳过20个字节大小，20的16进制是0x14,所以第一个printf的打印结果是0x100014

	printf("%p\n", (unsigned long)p + 0x1);
	//0x100000被强制转化位unsigned long类型的了，变成了一个数字，加一后，变成0x00100001,输出结果也是这个
	printf("%p\n", (unsigned int*)p + 0x1);
	//p原本是struct test*类型的指针变量，但是被强制转化为了，unsigned int*类型的了，也就是说p现在指向的是一个unsigned int类型的数据，还是一个指针变量，不过指向的对象类型变了
	//在进行加1，跳过sizeof(unsigned int)个字节，也就是4个字节，所以第三个printf的输出结果是0x00100004
	return 0;
}

int main()
{
	int a[5][5];
	int (*p)[4];
	p = a;
	printf("%p,%d\n", &p[4][2] - &a[4][2], &p[4][2] - &a[4][2]);

	return 0;

第七题

涉及知识

  1. 指针数组在内存中的存储
  2. 二级指针变量的解引用
  3. %s格式控制符号的刹车标志（\0）
#include<stdio.h>
int main()
{
	char* a[] = { "work","at","alibaba" };//指针数组，放的是char*类型的指针
	char* *pa = a;//pa是一个二级指针，char* *pa拆解分析，中间的*表示pa是一个指针，前面的
    //char* 表示pa作为一个二级指针变量指向的地址是char*类型的。
	pa++;//pa是一个二级指针变量，对其加1，跳过1个char* 字节大小的内存单元
	printf("%s\n", *pa);
    //打印结果？
    //at
	return 0;
}

题解：
- 前提知识：
这道题的关键点是理解指针数组里面放到到底是什么，在内存中是如何存储的。
数组a是一个字符型指针数组，里面放的是字符类型的指针，也就是每个字符串的首地址，知道这些东西后，我们还要知道这样写“字符串”，其实是自带一个'\0'结束符号的，用来告诉编译器字符串到这里就结束了。
- 核心点：
理解pa里面放的是什么，pa是一个二级指针变量，类型是char* *，里面放的是，一级指针变量的地址，也就是char* 类型的地址，然后，pa++，pa是一个指针变量，其指向的内容决定了其移动的步长，pa指向的内容是char* 类型的，在32位机器上，一共是4Byte，也就是4个内存单元，也就是移动4个字符，详细看下图。

第八题

涉及知识

  1. 指针数组
  2. 指针的解引用操作
  3. 自增自减运算符（++、--有副作用，会修改原来的值啊）
#include<stdio.h>
int main()
{
	char *c[] = { "ENTER","NEW","POINT","FIRST" };
	char* *cp[] = { c + 3,c + 2,c + 1,c };
	char** *cpp = cp;
	printf("%s\n", **++cpp);
	printf("%s\n", *-- * ++cpp + 3);
	printf("%s\n", *cpp[-2] + 3);
	printf("%s\n", cpp[-1][-1] + 1);
	return 0;
}

int main()
{
	char *c[] = { "ENTER","NEW","POINT","FIRST" };
	//数组c是一个char类型的指针数组，数组里面放的全是指向char数据的指针，指针类型是char*的，而数组名一般表示首元素的地址，
	//而数组c的首元素是地址，所以数组名c是一个二级指针，类型是char**
	char* *cp[] = { c + 3,c + 2,c + 1,c };
	//数组cp也是一个指针数组，不过数组cp是一个二级指针数组，里面放的是一级指针的地址,数组名表示首元素地址，可以理解为数组cp的元素是，&c[0]，&c[1]，&c[2]……这样的
	//所以数组cp里面放的是char**的数据。
	char** *cpp = cp;
	//cpp是一个三级指针变量，看赋值号右侧可以得知，cpp里面存放的是数组名cp，数组名一般指向首元素的地址，而cp的首元素是cp[0]，所以cp就相当于是
	//&cp[0]，所以数组名的类型就是char***的数据
	printf("%s\n", **++cpp);
	printf("%s\n", *-- * ++cpp + 3);
	printf("%s\n", *cpp[-2] + 3);
	//*cpp  等效 *（*(cpp-2)）+3
	printf("%s\n", cpp[-1][-1] + 1);
	//*(*(cpp-1)-1)
	return 0;
}
//第一个printf的结果：POINT
//分析：cpp是一个三级指针变量，先进行前置自增操作，移动cpp指向的位置，cpp指向的内容是char**类型的，原先指向&cp[0]，现在指向
//&cp[1]，然后进行解引用操作，第一个解引用操作结束后，我们得到是数组元素cp[1]的真实值，也就是一串地址，此时这段地址也就是c+2,表示POINT首元素地址的地址
//然后再对这串地址解引用操作就得到了字符串POINT首元素的地址，打印结果也就是POINT。
//第二个printf的结果是：ER
//由于上一次对cpp进行了前置++，所以cpp指向的位置已经改变了，指向指向cp[1]，
//分析：前置++后，cpp指向cp[2]，第一次解引用后得到了c+1的真实值，然后对这个真实值进行前置--操作，原本是c+1，类型是char**，现在是c,然后再次解引用，就找到了字符串
//ENTER字符串的首地址了，类型是char*的，指向的是char数据，由于指针类型的意义，对该地址进行加3，移动3个字节，也就得到了ENTER中字符E的地址，打印结果是ER
// 注意：由于对cpp进行了两次前置自增操作，所以此时cpp指向的是cp[2]
//第三个pritnf的结果是：ST
//第四个printf的结果是：EW
