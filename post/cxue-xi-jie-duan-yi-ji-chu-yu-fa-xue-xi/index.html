C++学习阶段（一）基础语法学习

2026-07-29 3 min read # C++学习笔记

C++学习

阶段一：学习C++基础语法
阶段二：C++核心知识（面向对象编程）
阶段三：C++提高编程（泛型编程思想、以及STL的基本使用）

第一阶段

第一个代码

#include<iostream>
using namespace std;
int main()
{
	cout << "This is my first c++ program!" << endl;
	system("pause");
	return 0;
}

C++常量

在C++里面用关键字const修饰一个变量时，此时这个变量就成为了常量。

const int month = 12;
int arr[month]={0};//这样写是对的，但是在C语言里面就不对了。

数据的输入

int a = 10;
cin >> a;

运算符

小数数据不能用于取余运算！

比较运算符

作用：用于表达式的比较，并返回一个真值/假值！

程序流程结构设计

选择、循环

数组

一维数组

一维数组名：

  1. 可以统计整个数组在内存中的长度.（sizeof(arr)）
  2. 可以获取数组在内存中的首地址。

函数

函数的声明可以有很多次，但是函数的定义可以有很多次！

函数的份文件书写

函数分文件编写一般有4个步骤:
1.创建后缀名为.h的头文件
2.创建后缀名为.cpp的源文件
3.在头文件中写函数的声明
4.在源文件中写函数的定义

指针

空指针

  1. 空指针用于给指针变量初始化
  2. 空指针是不可以被访问的

野指针

指针指向未知的空间

const修饰指针

  1. 常量指针
  2. 指针常量
    看const右侧紧跟着的是指针还是常量，是指针就是常量指针，是常量就是指针常量

struct结构体

  1. 结构体定义的时候struct关键字不可以省略。
  2. 创建结构体变量的时候struct不可以省略。

结构体嵌套结构体

总结：在结构体中可以定义另一个结构体作为成员，用来解决实际问题

结构体作为函数参数时

一共有两种传递方式：

  1. 值传递（创建临时副本，多占空间）
  2. 地址传递（无临时副本，节省空间）
