浮点数在内存中存储

这方面的知识不太重要，了解一下就行了
大概知道为什么一个浮点型数据是什么在内存是怎么存放的，为什么会有偏差，怎么拿出来的，就够了！
任意一个二进制浮点数V可以表示成下面的形式：
目前计算机界通用的浮点数存储标准叫 IEEE 754 标准
当然这种表示方式是给人看的，就像整型数据的原码一样，方便人们计算它的二进制，而不是十进制数！

**"二进制的科学计数法"**
(-1)^S * M * 2^E
(-1)^s表示符号位，当s=0，V为正数；当s=1，V为负数。
M表示有效数字，大于等于1，小于2(二进制)。
2^E表示指数位。

小数点后面的权重：2^-1 2^-2 2^-3 …………
实例：5.5

float f = 5.5f;
// 拆解：
//核心部分
// 101.1 
// (-1)^0 *1.011 * 2^2
// s:0 m: 1.011 e: 2

那么为什么浮点数会有片偏差呢？

v = 9.5f;
   //  1001.1
   //   (-1)^0 * 1001.1
   // (-1)^0 * 1.0011 * 2^3
   //s = 0     m = 1.0011 e = 3
   这样的数字好表达，但是可不是每个数字都是这样容易表达的
   v1 = 9.6f
     = 1001.100……//无限逼近，但就是达不到原数据
