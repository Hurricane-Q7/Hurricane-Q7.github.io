C语言进阶-程序的编译与预处理环节（一）

2026-05-30 5 min read

一个C源文件变成一个可执行程序的流程

大致流程是这样的：预处理/预编译->编译->汇编->链接
一个源文件想要成为一个可执行程序一般要经过这4个步骤，但是再日常中表达，我们一般把上述的4个步骤统称为编译.

常见的Compiler编译器:

  • GCC - Linux/跨平台，最广泛使用
  • Clang (基于LLVM) - macos / 跨平台，错误信息友好
  • MSVC - Windows 集成在Visual Studio

C源文件例子

假设有一个C语言源文件，名字叫main.c

#include <stdio.h>
#define MAX 100
int main()
{
    printf("%d\n", MAX);
    return 0;
}

编译器采用gcc！！！

对应个各个操作的gcc指令：
1. gcc -E 预处理
2. gcc -S 编译生成汇编代码
3. gcc -c 编译加汇编

第一步-预处理环节

Linux环境下对应指令：
gcc c源文件 -E -o test.i
预处理环节做了哪些事情？

  1. 头文件的包含（拷贝头文件到预处理后生成的文件中）
  2. define定义符号的替换，删除定义的符号
  3. 删除注释（注释是给人看的，机器看不懂）
  4. 条件编译（根据宏定义决定保留还是删除）

第二部-编译环节

gcc test.i -S
编译环节做了哪些事情？

  1. 把C语言代码转换成了汇编代码（不会改变C语言源文件）
  2. 语法分析、词法分析、符号分析、语义分析。
    注意：符号分析是把一些全局区的变量名和函数名给汇总起来，方便后续链接使用。

第三步-汇编环节

gcc test.s -c

  1. 将编译环节内生成的汇编代码给变成二进制机器码，并生成目标文件（.o后缀的文件）
  2. 结合符号汇总，形成符号表。

第四步-链接环节（变成可执行程序）

  1. 合并段表
  2. 符号表的合并与重定位

程序的运行环境

预处理详解

预定义符号

FILE      //进行编译的源文件
LINE     //文件当前的行号
DATE    //文件被编译的日期
TIME    //文件被编译的时间
STDC    //如果编译器遵循ANSI C，其值为1，否则未定义
用法：

#include<stdio.h>
//预处理详解
int main()
{
	int i = 0;
	for (i = 0; i < 10; i++)
	{
		printf("Files:%s Lines:%d date:%s Time:%s i的值:%d",__FILE__,__LINE__,__DATE__,__TIME__,i);//打印信息
	}
	return 0;
}

define定义标识符

这里很简单，define定义的标识符，在预处理阶段会发生替换
#define MAX 100中，MAX会被替换成100。
来看define的一些操作：

1. #define reg register //为register这个关键字，创建一个简短的名字
2. #define do_forever for(;;)
3. #define CASE break;case//在写case语句的时候，自动把break加上

//来看一下这个骚操作
#define CASE break;case
switch()
{
    case 1:
    CASE 2:
     CASE 3:
     CASE 4:
     break;
}

注意：在使用define关键字的时候，在最后define后面最好不要加上分号.
#define MIN 100;不要加分号，以防止习惯性而导致语法错误！！！

define定义宏（macro）

definition:#define 机制包括了一个规定，允许把参数替换到文本中，这种实现通常称为宏（macro）或定义宏（define macro）。
下面是一个简单的宏定义：

#include<stdio.h>
#define DOUBLE(x) x+x
int main()
{
    int r = 0;
    scanf("%d",&r);
    int value = DOUBLE(r);
    printf("the value of r is %d",value);
    //这里实际上是发生替换的，DOUBLE替换成了，
    //int value = r*r;的
    //所以，我们定义的宏，实际上也是会发生替换的
    return 0;
}

上面的写法是存在问题的:
当宏体内出现额外的运算符号后：
int value = DOUBLE(5+1);
//这样写之后可能就出现了不是预期的结果，因为在给宏体传参的时候，不是把5+1这个表达式计算后传过去的，而是把5+1表达式这个整体视为一个参数给传过去的，简单来说就是直接替换。
//实际替换结果是这样的：
int value = 5+1*5+1;
//这样的实际结果就是11了，更本不是我们想要的36，这说明我们的宏定义是有问题的
更改后：
#define DOUBLE(x) (x)+(x)//这样写确实解决了上述的问题，但是还是有些问题呢
int main()
{
    int value = 10*DOUBLE(2+1);
    //10*(2+1)+(2+1)
    //我们理想的结果是60，但是实际上是33，看来还是有问题的，还得改
    //更改后:define DOUBLE(x) ((x)*(x)) 
    return 0;
}
