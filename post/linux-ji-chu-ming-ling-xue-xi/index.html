基础命令之搜索指令

locate（非实时指令，查看DB）

指令简介：locate也是一种搜索指令，特点是快，缺点是非实时搜索（比如你刚创建的一个.c文件，然后你一个locate一下这个文件就找不到的，需要及时更新一下数据库，用updatedb指令）

工作原理：locate 的速度为什么快？因为它不是像 find 一样实时遍历目录，他会提前建立一个文件路径数据库，搜索时直接查数据库，所以特别快，但是数据库可能不是最新的，因此有时候需要更新一下。
用法：locate 文件名/文件名包含的字符串

find (实时搜索指令，查看DISK，在书架上找书)

按文件名搜索


用法：find 搜索路径 [选项] 搜索内容
eg: find / -name main.c

1. -iname不看大小写
2. name 看大小写

按文件大小搜索

用法：find 搜索路径 -size [+|-]大小
find / -size +1M

按文件类型找


用法：find 路径 -type 类型字符(f,d,l,b,c,s,p
注意：ls -l 中的文件类型标签字符，不代表find -type 的参数，在ls -l里面-表示普通文件，但是在find里面用f来表示

grep(最细的搜索指令，在书里面找词语)

用法（命令格式）：grep [选项] "搜索内容" 文件名
作用：在文件中提取和匹配符合条件的字符串
选项：

  • -i 忽略大小写
  • -n 输出行号（指符合条件的字符串行在文件内的行号）
  • -v 反向匹配，搜索不包含匹配内容的行
  • --color=auto 搜索出的关键字用颜色表示

Linux基础之软件安装（Centos 7）

YUM：CentOS的软件包管理器。
核心命令： yum
命令格式： yum [选项] 命令
yum命令的过人之处：

  1. 自动处理依赖（自动查找、自动分析、自动安装、自动下载、自动安装顺序）
  2. 统一的软件安装来源（aliyun等等）
  3. 统一更新。（可以更新单个软件、更新整个系统）
  4. 方便查询（搜索软件、查看软件信息、查看仓库）
  5. 方便卸载（卸载软件、自动处理依赖）

软件安装后的分布情况

在Linux上面安装软件（用yum安装包管理器）可不像Windows上面一个目录下就把安装的全部内容放一块了，而是把配置文件、可执行程序、帮助文档、日志单独放到对应的目录下。

可执行的命令-真正的程序

安装目录：/usr/bin

配置文件

安装目录：/etc

动态库文件

安装目录：/usr/lib

与cpu架构无关的数据

目录位置：/usr/share

  • 帮助文档（man）
  • 图标
  • man手册
  • 语言包
  • 模板

经常变化的数据-日志(/var/log)

目录位置：/var

  • 日志
  • 缓存
  • 数据库
  • yum缓存(/var/cache/yum)

模式切换

掌握不同进入插入模式的方法。

光标移动

快速移动

^      行首第一个非空字符
$      行尾
gg     文件开头
G      文件结尾
nG     跳到第n行(底线命令模式':n')

单词级移动：

w   下一个单词开头

删除操作（重点）

1. x 删除字符
2. dw 删除单词
3. D 删除到行尾<=>d$
4. dd 删除当前一整行
5. ndd 从当前开始删除n个行

copy and paste

COPY

  1. yy 复制当前行
  2. nyy 复制多行（n为从当前行开始要复制几行）
    PASTE
  3. p 当前行下面粘贴
  4. P 当前行上面粘贴

撤销与恢复

  1. u 撤销
  2. Ctrl+r 反撤销

查找

  1. /关键字
    查找后：n下一个结果，N上一个结果
    • 当前单词搜索

替换（重点）

注意：这里的替换操作需要提前进入底线命令模式！

单行替换

命令格式：
:ns/old/new/g，第n行的old用new来替换。

多行替换

命令格式：
:n1,n2s/old/new/g
作用：替换n1行到n2行，用new替换old。

全文替换

命令格式：
:%s/old/new/g
把全文的old用new来替换。

选中(Visual模式)

  1. v 字符选择
  2. V 行选择
  3. Ctrl + v 块选择
