运算符重载：递增、赋值、关系、函数调用重载

递增运算符重载

//# 重载自增运算符++ --
// 自增运算符的两种使用场景
// 1. 前置++ （先自增一遍，增完后，再返回结果）
// 2. 后置++  （先返回当前值，返回后再作自增）
class MyInteger
{
	friend ostream& operator<<(ostream& cout, MyInteger& myInt);
public:
	MyInteger(int a)
	{
		this->my_Int = a;
	}
	//重载自增运算符-前置++
	//返回引用，返回对象本身，用于连续操作
	MyInteger& operator++()
	{
		this->my_Int++;
		return *this;
	}
	//重载后置自增++
	//后置先返回临时值，创建一个新的副本，随后再++
	MyInteger operator++(int)
	{
		//创建一个临时对象，用于记录当前自增对象的值，便于返回
		MyInteger tmp(0);
		tmp = this->my_Int;
		this->my_Int++;
		return tmp;

	}
private:
	int my_Int;
};
//重载左移运算符，操作对象必须是引用
ostream& operator<<(ostream &cout,MyInteger &myInt)
{
	cout << myInt.my_Int;
	return cout;
}
//前置++ 测试
void test01()
{
	MyInteger M1(1);
	cout << "M1自增前：" << M1 << endl;
	cout <<"自增后："<< M1 << endl;
	//如果返回MyInteger的话，MyInteger operator++() 本身是合法的；真正的问题是它返回的临时对象无法绑定到 operator<< 的 MyInteger& 参数。

}
//后置++ 测试
void test02()
{
	MyInteger  M1(1);
	MyInteger tmp2(0);
	cout << "M1自增前：" << M1 << endl;//1
	tmp2 = M1++;
	cout << "M1++ 临时值" <<tmp2 << endl;
	cout << "M1 = " << M1 << endl;;
}

赋值运算符重载

C++编译器至少给一个类添加4个函数

  1. 默认构造函数(无参，函数体为空)
  2. 默认析构函数（无参，函数体为空）
  3. 默认拷贝构造函数，对属性进行值拷贝
  4. 赋值运算符 operator=，对属性进行值拷贝
    如果类中有属性指向堆区，做赋值操作时也会出现深浅拷贝问题。
class Person
{
public:
	Person(int age)
	{
		this->my_Age = new int(age);
		//在堆区动态申请一块 int 类型的内存，并且用 age 初始化它，然后把这块int类型的地址放到this->my_Age中
		//堆区的内存由程序员手动申请，并且还要手动释放
	}
	Person& operator=(Person& p1)
	{
		//先判断调用该函数的对象的成员属性是否为空，如果不为空，要先释放
		if (this->my_Age != NULL)
		{
			delete this->my_Age;
			this->my_Age = NULL;
		}
		//深拷贝，就是重新开辟一块内存空间来存储
		this->my_Age = new int(*p1.my_Age);
		return *this;
	}
	~Person()
	{
		if (my_Age != NULL)
		{
			delete my_Age;
			my_Age = NULL;
	    }
	}
	int* my_Age;
};
int main()
{
	Person p1(18);
	Person p2(20);
	Person p3(30);
	p1 = p2 = p3;
	//这里用的拷贝函数是编译器默认给的，执行的是浅拷贝操作，此时p1.my_Age 和 p2.my_Age指向的是同一块内存空间
	//彼此在结束时都会执行一遍析构函数，因此会发生对同一快内存空间重复释放的问题
	cout << "p1的年龄是：" << *p1.my_Age << endl;
	cout << "p2的年龄是：" << *p2.my_Age << endl;
	cout << "p3的年龄是：" << *p3.my_Age << endl;
	system("pause");
	return 0;
}

关系运算符

class Number
{
public:
	Number(int a,int b)
	{
		this->n_a = a;
		this->n_b = b;
	}
	bool operator==(Number& N1)
	{
		if (this->n_a == N1.n_a && this->n_b == N1.n_b)
		{
			//相等
			return true;
		}
		return false;
	}
	int n_a;
	int n_b;
};
int main()
{
	Number N1(10, 20);
	Number N2(10, 20);
	if (N1 == N2)
	{
		cout << "相等！" << endl;
	}
	else
	{
		cout << "不相等!" << endl;
	}
	system("pause");
	return 0;
}

函数调用运算符重载

  • 函数调用运算符（）也可以重载
  • 由于重载后使用的方式非常像函数的调用，因此称为仿函数
  • 仿函数没有固定的写法，非常灵活
