输入一个字符串来实现逆序输出

void show_overturn(char* str, int num_str)
{ //算法思想：先得到数组首地址，然后通过指针加减运算来得到数组末端元素地址，得到后解引用输出，随后向前调整
    //abcdefghij
    int i = 0;
    for (i = num_str - 1; i >= 0; i--)
    {
        printf("%c", *(str + i));
    }
}
int main()
{
    char str[10000] = { 0 };
    fgets(str, sizeof(str), stdin);
    int num_str = strlen(str);//只统计'\0'之前的字符个数
    while (num_str > 0 && (str[num_str - 1] == '\n'))
    {
        str[num_str - 1] = '\0';
    }
    show_overturn(str, num_str);//实现逆序并输出
    return 0;
}

fgets函数（标志输入字符串）

函数模型：char *fgets( char *string, int n, FILE *stream );

fgets读取规则（关键！）
停止条件：满足以下任一条件就停止读取：

  1. 读到 \n（换行符，按回车产生），且 \n 会被包含在读取的字符串中；
  2. 已读取 size-1 个字符；
  3. 读到流的末尾（EOF）。
    自动补终止符：无论哪种停止条件，都会在读取的字符末尾加 \0，保证是合法字符串；
    返回值：
  • 成功：返回 str 的地址,也就是首地址（可忽略，只要数组合法基本都成功）；
  • 失败 / 读到末尾：返回 NULL（比如文件读完了）。
int main() {
    char str1[100] = { 0 }, str2[100] = { 0 };

    printf("用scanf输入带空格的字符串：");
    scanf("%s", str1);  // 输入：test 123
    printf("scanf读取结果：%s\n", str1);  // 输出：test（空格后被截断）

    // 清空输入缓冲区的残留换行（否则fgets会直接读空）
    //while (getchar() != '\n');

    printf("用fgets输入带空格的字符串：");
    fgets(str2, sizeof(str2), stdin);  // 输入：test 123
    int len = strlen(str2);
    if (len > 0 && str2[len - 1] == '\n') str2[len - 1] = '\0';
    printf("fgets读取结果：%s\n", str2);  // 输出：test 123（完整读取）

    return 0;
}//可见如果没有清理缓冲区的情况下，fgets会从直接从缓冲区读字符

输出0~10000的水仙花数

水仙花数：一个数字一共有n位,如果每一位的n次方和等于该数字本身，那么就为“水仙花数”！比如153=1^3 + 5^3 + 3^3;

逻辑：产生数字->判断满足不满足要求->满足输出/不满足不输出
int main()
{
	int i = 0;
	for (i = 0; i <= 10000; i++)//产生数字
	{
		//判断数字满足不满足水仙花数的要求
		//1. 先拿到每个数字的位数
		//2. 看满足不满足和
		int sum = 0;
		int every_i_digit = 1;//一个数字最起码有一位数，不可能以为也没有!
		int temp = i;//循环变量在循环体内不能修改！！！
		while (temp/10)//计算位
		{
			every_i_digit++;
			temp /= 10;//<=>temp = temp/10
		}
		temp = i;
		//判断位的n次方和和数字等不等
		while (temp)
		{//1234
			sum += pow(temp % 10, every_i_digit);
			temp /= 10;// 每一去掉后一位，1234->123->12->1
		}
		if (sum == i)
		{
			printf("%d ", i);
		}
	}
	return 0;
}
