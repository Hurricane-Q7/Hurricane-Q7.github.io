4.19日-C语言-自定义类型结构体

2026-04-19 3 min read # C语言学习笔记

结构体

struct 类型名
{
   member_list;//成员列表
}variable-list;//变量列表，分号不能丢！

结构是一些值的集合，这些值称为成员变量。结构的每个成员可以是不同类型的变量。
C语言提供了很多的内置数据类型，比如int、float、char、long 、long long 、double，这些类型足以涵盖日常生活中的数据了，但是在描述一个比较复杂的人或物时，有点麻烦，这时候C语言给我提供了一个自定义数据类型结构体，我们可以把一些数据类型整合、打包成一个整体来作为一个结构体类型。
比如，学生为例，学生有姓名、年龄、身高、得分、学号等等，我们可以通过自定义数据类型结构体来实现对一个学生的描述。

//定义一个数据类型
 struct student
 {
         char name[20];//名字
         int age;//年龄
         float height;//身高
         int score;//得分
         //通过这种方式，我们就自定义了一个数据类型，类型是struct student，后续也可以通过该类型来创建变量。
 }s2;//创建struct student类型的变量s2
 //这两种创建变量的方式是相同的！
 int main()
 {
     struct student s1;//创建struct student类型的变量s1
     return 0;
 }

匿名结构体类型

只能使用一次！

struct 
{
    char name[20];
    int age;
}s1;

结构体的自引用

自引用： 在结构中包含一个类型为该结构体本身的成员。（形式有点像函数的递归调用，自己调用自己）

代码一

struct Node//声明一个struct Node的数据类型
{
    int data1;//4Byte
    struct Node next;
}
这样写是有问题的，就是我们不知道struct Node的字节大小，我们在成员列表中又拿起了struct Node 数据类型创建了一个变量next,next中又有对应的节点和下一个节点，而下一个节点我们同样也不知道大小，因为struct Node这个数据类型我们都不知道！

正确写法

struct Node
{
    int data1;
    struct Node* next;//存放下一个节点的指针，指针的大小是固定的（4/8byte）;
}

代码二

typedef struct
{
    int data;
    Node* next;// 错误：此时编译器还不认识 Node 是什么
}Node;
//这里的代码创建了一个匿名结构体类型，又用这个结构体类型创建了一个变量Node，而在结构体内部又调用了Node变量，这里又歧义，到底是先有变量类型，还是先有变量类型的指针（Node* next)。

正确写法

typedef struct Node
{
 int data;
 struct Node* next;//拿起struct Node*这个类型来创建一个 指针变量
}Node;//这里的Node是struct Node的别名

//typedef是个数据类型起一个别名，在这里typedef struct Node后 struct Node 等价于 Node
struct Node s1;
//二者是等价的……
Node s2;
