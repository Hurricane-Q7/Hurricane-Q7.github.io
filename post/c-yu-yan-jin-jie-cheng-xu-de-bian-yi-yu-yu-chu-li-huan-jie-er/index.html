宏的一些基本操作

宏的多行定义

宏不单单是可以定义一行语句，可以定义多行语句，具体写法如下

#define 宏名()    \
    语句1;       \
    语句2;       \
    语句3;
    //最后一行语句不加反斜线
    //宏的本质就是文本替换，再使用该宏后实际上就是：
    语句1；
    语句2；
    语句3；

下面是一个更加规范的写法：

//这样写不容易出问题，更规范一些！
#define HELLO()           \
do {                      \
    printf("Hello\n");    \
    printf("World\n");    \
} while(0)

条件编译

常见写法1

这些写的作用是防止该头文件被重复编译。

#ifndef 头文件名
#define 头文件名
//头文件的内容
#endif

文件包含

文件包含一共有两种方式：
#include<stdio.h>
#include"test.h"
一种是尖括号，一种是双引号。
这两种方式的主要区别是查找策略不同：

1. 尖括号的查找策略是从标准路径下去查找，如果找不到就报错。
eg：VS环境的标准头文件的路径：
C:\proaram Files (x86)\Microsoft VisualStudio 12.o\VC\include
2. 双引号包含的头文件查找策略是先在源文件所在目录下查找，如果该头文件未找到，编译器就像查找库函数头文件一样在标准位置查找头文件。

一句话：引用标准库文件的时候用<>，引用自己的本地文件的时候用""。
