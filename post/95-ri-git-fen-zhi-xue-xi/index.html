9.5日-Git分支学习

2026-09-06 2 min read

git分支

查看分支：git branch
创建分支：git branch <name>
切换分支：git checkout <name> 或者 git switch <name>
创建且切换分支：git switch -c <name> 或者 git checkout -b <name>
把某分支合并到当前分支：git merge <name>;//注意：
//这里的name是被合并过来的分支名称，而不是当前分支
删除分支：git branch -d <name>

git 自动合并冲突

当Git无法自动合并分支时，就必须首先解决冲突。解决冲突后，再提交，合并完成。
解决冲突就是把Git合并失败的文件手动编辑为我们希望的内容，再提交。
用git log --graph命令可以看到分支合并图。

gir分支合并 (非快速模式-普通模式合并)

git merge --no-ff -m "提交信息" <branch>
采用普通模式合并分支，一定要加上--no-ff字符，由于会保留一次提交信息，所以也要加上-m
