C++学习-类与对象（3）运算符重载

2026-09-05 6 min read # C++学习笔记

运算符重载

概念：对已有的运算符重新进行定义，赋予其另一种功能，以适应不同的数据类型。
因为我没不能对自定义对象进行运算操作，所以运算符重载其实就是给一些我们定义的复杂对象提供的一种全新的运算操作符，其实本质上就是函数的一个调用。
operator 是关键字，operator+ 是用来定义 + 运算符重载的特殊函数名。;

总结1：对于内置的数据类型的表达式的运算符是不可能改变的。(只面向自定义数据类型)
总结2：不要滥用运算符。

加号运算符重载

{
public:
	Person()
	{
		this->m_A = 10;
		this->m_B = 20;
	}
	//类内运算符重载：
	//Person operator+(Person &p)

	//	tmp.m_B = this->m_B + p.m_B;

	int m_A;

//全局函数重载+运算符
Person operator+(Person& p1, Person& p2)
{
	Person tmp;
	tmp.m_A = p1.m_A + p2.m_A;
	tmp.m_B = p1.m_B + p2.m_B;
	return tmp;
}

{

	Person p2;
	//Person p3 = p1 + p2;

	Person p3 = p1 + p2;
	//全局函数重载运算符本质是函数调用：
	//本质写法：Person p3 = operator+(p1,p2)

//运算符重载也可以发生函数重载
class Person
{
public:
	Person()
	{
		this->m_A = 10;
		this->m_B = 20;
	}
	//类内运算符重载：
	//实现对象与对象之间的加法运算
	Person operator+(Person& p)
	{
		Person tmp;
		tmp.m_A = this->m_A + p.m_A;
		tmp.m_B = this->m_B + p.m_B;
		return tmp;
	}
	int m_A;
	int m_B;
};
//类外运算符重载：
//实现对象和int类型之间的加法运算
Person operator+(Person& p, int num)
{
	Person tmp;
	tmp.m_A = p.m_A + num;
	tmp.m_B = p.m_B + num;
	return tmp;
}
int main()
{
	Person p1;
	Person p2;
	Person p3 = p1 + p2;
	cout << "类内运算符重载：对象与对象之间的加法结果：" << endl;
	cout << "p3.m_A = " << p3.m_A << " p3.m_B = " << p3.m_B << endl;
	cout << "类外运算符重载：对象和整数之间的加法：" << endl;
	Person p4 = p1 + 100;
	cout << "p4.m_A = " << p4.m_A << " p4.m_B = " << p4.m_B << endl;
	system("pause");
	return 0;
}

左移运算符重载

左移运算符：<<;
在C++里面输出数据经常用cout加左移运算符来配合，但是左移运算符原来是不具备这种功能的，所以在C++里面，C++标准库对重载了左移运算符，使其可以用于输出各种标准类型的数据（运算符重载函数也可以发生函数重载），使 << 运算符可以配合 ostream 输出流对象，将不同类型的数据写入输出流。，而cout这个东西，实际上就是一个ostream类的一个对象，标准输出流对象，，每次写cout<<的时候，实际上就是对左移运算符重载函数的一次调用罢了。

cout <<"hello world!";
operator<<(cout,"hello world!");
//这两句代码的作用是一样的，第二行是第一行的本质写法，第一行是简化版本

由于现在的左移运算符可以数据标准类型数据了，但是不可以输出自定义的数据类型，因此我们可以进行再次运算操作符重载，达到输出我们自定义类-对象信息的作用。
一句话总结：

cout 是标准输出流对象；<< 是运算符；operator<<() 是对应的运算符重载函数。通过对 operator<< 进行重载，可以规定不同类型的数据应该如何输出。

class Person
{
public:
	//全局函数作友元，给予全局函数访问Person类内私有权限的成员属性的权限！！！
	friend ostream& operator<<(ostream& cout, Person& p);
	Person(int a,int b)
	{
		this->m_A = a;
		this->m_B = b;
	}
private:
	int m_A;
	int m_B;
};
ostream& operator<<(ostream& cout, Person& p)
{
	cout << "p.m_A = " << p.m_A << " p.m_B = " << p.m_B;
	return cout;
}
void test01()
{
	Person p(10, 10);
	cout << p << endl;
}
//用全局函数来重载运算符，不用类内成员函数

int main()
{
	test01();
	system("pause");
	return 0;
}
