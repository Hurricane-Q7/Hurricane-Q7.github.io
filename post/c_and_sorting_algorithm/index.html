C语言-排序和二分查找程序设计

2026-03-29 3 min read # C语言学习笔记

冒泡排序

冒泡排序是一个简单的排序算法。
核心算法思想：假如有N个数字，我们要对其进行排序，每趟可以将一个数字排好序，那么N个数字共需要N-1趟来排序，在一趟内部，我们让相邻数字两两比较，按照我们想让它们排成的顺序来比较相邻数字，不满足顺序就交换！

void bubble_sorting(int arr[], size_t len_of_arr)
{
	int i = 0;
	int j = 0;
	int tmp = 0;
	for (i = 0; i < len_of_arr - 1; i++)
	{
		//外层循环解决趟的问题
		for (j = 0; j < len_of_arr - 1 - i; j++)
		{
			//内层循环解决一趟内不进行比较的次数
			if (arr[j] > arr[j + 1])
			{
				tmp = arr[j];
				arr[j] = arr[j + 1];
				arr[j + 1] = tmp;
			}
		}
	}
}

选择排序

基本思想：在每一轮排序中，我们从未排序区域找出最小的元素，将它放到未排序区域的最前面。通过不断重复这个过程，整个数组最终会变成有序的。
选择排序的重要特点：

  1. 对于n个数据，的排序，我们只需要执行n-1轮，因为每轮都确定一个元素的最终位置。
  2. 需要通过一个变量(p)来记录未排序区域中最小值的位置。
  3. 每一轮排序只需要执行一次交换操作。
#include<stdio.h>
void sort(int* array,int n)
{
    int i = 0;
    int j = 0;
    int p = 0;//变量p用来记录最小元素下标（最初假设是arr[0]）
    //外层for循环控制对n个数字要进行几轮选择
    int tmp = 0;
    for(i=0;i<n-1;i++)
    {
        p = i;
        for(j=i+1;j<n;j++)
        {
            //内层循环控制对数组元素的比较，与更新最小元素下标
            //遍历i+1后的数组元素，与arr[p]比较,如果arr[j+1]小于arr[p]，更新p的值
           
            if(*(array+j)<*(array+p))//array[j]<array[p]
            {
                p=j;
            }
        }
        if(p!=i)
        {
            tmp = *(array+p);       //tmp = array[p]
            *(array+p) = *(array+i);//array[p] = array[i]
            *(array+i)=tmp;         //array[i] = tmp
        }
    }
}
void print_arr(int* array,int n)
{
    int i = 0;
    for(i=0;i<n;i++)
    {
        printf("%d ",*(array+i));
    }
}
int main()
{
    int n = 0;
    scanf("%d",&n);//输入n，数组长度
    int array[n];
    int i = 0;
    for(i=0;i<n;i++)
    {
        scanf("%d",&array[i]);//为数组中的每个元素赋值
    }
    sort(array,n);
    //先排好序（升序）

    print_arr(array,n);

    //然后再输出数组
    return 0;
}
