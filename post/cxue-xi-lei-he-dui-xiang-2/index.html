友元

友元（friend）本质上是在解决“类外部代码想访问类的私有成员”这个问题。

全局函数作友元

class Building
{
	friend void bestFriends(Building& B1);
	//核心语法关键字：friend，
	//作用：告诉编译器某一个全局函数可以访问类内的成员变量。
public:
	Building()
	{
		this->m_bedroom = "卧室";
		this->m_settingroom = "客厅";
	}
	string m_settingroom;
private:
	string m_bedroom;
};
//全局函数：
void bestFriends(Building &B1)
{
	cout << "好朋友正在访问：" << B1.m_settingroom << endl;
	cout << "好朋友正在访问：" << B1.m_bedroom << endl;
}
int main()
{
	Building B1;
	bestFriends(B1);
	system("pause");
	return 0;
}

友元类

语法书写：

class Myhome
{
    friend class BestFriend;//我允许我最好的朋友可以访问我家，BestFriend类可以访问Myhome类中的成员
    //BestFriend:友元类
    //Myhome：被友元类访问的类，权限的授予者
}

class Building
{
	friend class myBestFriend;
	//声明：myBestFriend这个类向Building类提供了访问权限，此时myBestFriend这个类可以访问Building类中的成员
public:
	Building()
	{
		SettingRoom = "我的客厅！";
		BedRoom = "我的卧室！";
	}
private:
	string SettingRoom;
	string BedRoom;
};
class myBestFriend
{
public:
	void visitBuilding(Building &B1)
	{
		cout << "我最好的朋友正在参观" << B1.BedRoom << endl;
		cout << "我最好的朋友正在参观" << B1.SettingRoom << endl;
	}
};
int main()
{
	Building B1;
	myBestFriend F1;
	F1.visitBuilding(B1);
	system("pause");
	return 0;
}
注意事项：
1. 友元关系是单向的（你允许我访问，不代表我也允许你访问）
2. 友元关系不具备传递性。   
3. 友元不能继承。

成员函数作友元

友元类和成员函数作友元的区别如下：

**友元类：**友元类中的所有成员函数，都可以访问被授予权限的那个类的 private 和 protected 成员。
**成员函数作友元：**让另一个类中的某一个成员函数，获得访问当前类 private 和 protected 成员的权限。
正确代码示例：

#include<iostream>
#include<string>
using namespace std;
//成员函数作友元
class Building;//单写一个class Building只能上编译器知道有这个类，但是类里面具体有什么是不知道的
class GoodGay
{
public:
	    void visit1(Building& B1);
		void visit2(Building& B1);
};
class Building
{
public:
	friend void GoodGay::visit1(Building& B1);
	Building()
	{
		this->m_SettingRoom = "我的客厅";
		this->m_BedRoom = "我的卧室";
	}
	string m_SettingRoom;
private:
	string m_BedRoom;
};
void GoodGay::visit1(Building& B1)
{
	cout << "好朋友v1正在访问：" << B1.m_SettingRoom << endl;
	cout << "好朋友v1正在访问：" << B1.m_BedRoom << endl;
}
void GoodGay::visit2(Building& B1)
{
	cout << "好朋友v2正在访问：" << B1.m_SettingRoom << endl;
	//cout << "好朋友v2正在访问：" << B1.m_BedRoom << endl;
}
int main()
{
	Building B1;
	GoodGay gg;
	gg.visit1(B1);
	gg.visit2(B1);
	system("pause");
	return 0;
}

关于友元类我踩的坑

  1. 混淆了编译器的编译和运行流程；
编译是编译，运行是运行。
编译：编译器大体按照源代码顺序从上往下分析代码。（从第一行读到最后一行）
运行：程序运行时从 main() 开始执行。
虽然 main() 里面第一句创建了 B1，
但这并不意味着编译器会先处理 main()。
编译器必须先把前面的类、函数等代码分析清楚，最后才能生成可执行程序。
而我以为编译是从main函数开始的，遇到函数或类在向main去找对应的定义，而实际上是从上到下开始分析代码的，这也是为什么我的vs26报错“Building类未定义”，因为编译器只知道有这个类，但是不知道类的定义（不知道类里面有什么）。
